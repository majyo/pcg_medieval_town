# 道路几何定型

> 2026-11-08 新设计见 [道路系统三阶段设计](ROAD_SYSTEM_DESIGN.md)。本文的占地与来源契约作为复用依据，旧几何算法及验收数字不代表新方案已实现。

更新日期：2026-11-04。

## 流程位置

定型属于 **03 道路生成** 内部。一次生成依次完成路网规划、拓扑整理、几何定型、完整检查和结果发布，然后结束。04 街区与地块、05 建筑体量使用这次发布的结果；没有引入生长模拟或额外的运行节点。

```text
环境采样 → 聚落布局（含城墙占位）
         → 03 道路：路网规划 → 几何定型 → 发布 RoadNetwork
         → 04 街区与地块 → 05 建筑体量 → 场景布置
```

后续场景道路资源应消费定型占地；如果需要改变走向、路口或平面占地，必须回到道路节点重跑并使下游过期。

## 定型规则

- 保留路段 ID、首尾拓扑节点、入口、城门和公共院区锚点，不移动真实路口。
- 对边内部的折点使用切线方向约束的二次曲线，平顺距离同时受参数和相邻段长限制。重新检查整条中心线纵坡、全宽、交叉关系与环境限制；缩小尝试仍不合法时保留原折线。
- 按路口各分支的截面生成有界的展开区域。主次路交汇的窄分支在端部向最大接入宽度过渡；受限时保留原净宽并记录原因。区域入口保持平端，不向采样边界外生成端帽。
- 转角、展开或加宽不得制造与无关道路的新接触。既有路网仍由规划阶段负责选线和交叉拆分。
- 道路、路口统一做多边形并集，保留孔洞。不把独立的矩形和端帽直接叠加成渲染路面。
- 路口优先拥有中部路面，其余路段扣除已占区域，形成内部不重叠的面片。边界按实际来源拆分并关联路段；路口边界和端盖不作为可建宅地的临街边。
- 所有修正为有限的几何计算。回退原因单独输出，不将预览或失败草稿发布为有效下游输入。

“转角平顺”控制曲线的空间尺度，不是工程道路设计的最小转弯半径保证。平顺范围默认 3 米，路口展开默认 2 米，保留小尺度中世纪街巷的曲折结构。

## 数据契约

| 输出 | 含义与消费者 |
| --- | --- |
| `RoadNetwork.Edges` | 定型中心线、原拓扑与路段 ID、宽度、重新计算的长度和最大纵坡 |
| `RoadNetwork.Geometry.Area` | 唯一权威二维占地，包含外轮廓与孔洞；用于地块扣除、田园裁切、点查询及后续道路资源 |
| `Geometry.Surfaces` | 内部不重叠的路段/路口面片，附路段与路口节点来源；用于路面分色和生成 |
| `Geometry.Boundaries` | 带来源的占地边界及 `AllowsFrontage` 标记；用于临街识别，不以最近中心线猜测归属 |
| `Geometry.PlannedEdges` | 定型前的规划中心线快照，用于对照与诊断 |
| `Geometry.Notices` | 转角、路口展开、宽度过渡等回退原因与位置 |
| `RoadNetwork.Footprint` | 兼容接口：权威占地的无重叠三角片。新消费者直接使用 `Geometry.Area`，不从预览网格反推占地 |

04 节点沿真实街区边界与 `Geometry.Boundaries` 的重合区间提取临街边，继承 `RoadId`。可建筑带和建筑朝向沿这条边计算。道路定型参数改变后，旧地块与旧建筑继续显示为过期，必须重跑。

## 预览与操作

在 **03 道路生成** 中调整“转角平顺 / m”和“路口展开 / m”，点击“独立生成道路”。节点完成前不发布中间占地。“定位路口 / 近景”可检查细部。

| 图层 | 内容 |
| --- | --- |
| 路网总览 | 定型后的不透明路面，按主次路分色 |
| 连接关系 | 定型中心线、真实拓扑节点与选中入口通路 |
| 道路占地 | 路段金色、路口紫色；浅色边为可临街边界，紫边为路口预留 |
| 坡度与问题 | 路段纵坡分色、被拒候选；橙圈为定型回退，悬停查看原因 |

预览直接使用 `Surfaces`，按环境采样三角形裁切后取高程，避免长三角片跨过地表起伏。路面只绘制一次，建筑视图启用深度测试。这里仍是预览网格，正式路面材质、横坡、路缘、排水、土方、碰撞及导航尚未实现。

## 验证入口

```powershell
.\tools\project.ps1 test-roads
.\tools\project.ps1 test-parcels
.\tools\project.ps1 test-buildings
.\tools\project.ps1 test-regional
.\tools\project.ps1 test-road-geometry-ui
```

道路检查包含直路平端、内部转角、T 口、四路口、锐角、不同宽度、窄通道、禁建角、起伏地表、固定种子复现，以及定型阶段取消不发布部分结果。检查面片面积账目、占地覆盖、网格贴地与来源引用。地块验证检查临街边确实来自定型边界，建筑与区域验证沿用三组地图种子。

曲线附近的布尔切分可能产生零面积回折或顶点接触另一条边的轮廓。三角化使用私有副本清理回折、拆分接触环并核对三角形面积，必要时按扫描条带处理孔洞。小于 1 平方厘米的微小碎片保留土地归属和面积，只省略无法稳定表达的网格。剩余空地遇到不合法接触轮廓时，按 0.01–0.2 毫米逐级分离并检查面积变化不超过 0.1 平方米；整体土地账目仍使用原有检查。回归输入保存在 `configs/tests/road_boundary_spur.json`、`road_boundary_touch.json` 和 `road_boundary_micro_sliver.json`。

数据报告写入 `artifacts/road_geometry_validation.json`。界面验证保存 `artifacts/captures/roads_final_*.png`，包含总览、路口、边界、转角及建筑衔接。

## 本次验收结果

默认地图保留 58 个路网节点、90 条路段、33 个闭合回路和 3 个区域入口。定型完成 55 处转角平顺、42 处路口处理；4 处受约束的修正保留原形并附诊断。统一占地约 34,219 平方米。下游生成 848 个地块、649 栋主屋、5 个院区体块及 55 处共墙关系。

构建零警告、零错误；地图、环境、聚落、道路、地块及建筑完整数据验证通过。道路定型检查 2,526 项，地块检查 5,107 项，建筑三组种子检查 27,198 项；另有区域三组种子检查 313 项。实际 Godot 界面流程验证四层预览、几何参数局部重跑、上下游失效和地块/建筑衔接，保存五张截图。
