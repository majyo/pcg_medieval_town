# 城镇区域布局：实现与使用

更新日期：2026-11-03。状态：新的陆路区域预设已接入四个节点。以 [区域布局重做方案](REGIONAL_TOWN_LAYOUT_REDESIGN.md) 为依据，现有环境采样、几何运算与节点生命周期继续复用。

## 使用流程

1. 运行环境采样，默认覆盖整个 2 × 2 公里地图。
2. 选择 **02 城镇区域布局**，独立生成。默认得到设防核心、三条城外街带、一处独立修道院聚落和田园用地。
3. 选择 **03 道路生成**，生成核心内外的完整道路。区域入口 E 与城门 G 独立，多个区域通路可以服务于同一城门。
4. 选择 **04 街区与地块**，生成各片区的实际宅地；面板分别显示城内、城外宅地面积。

“定位布局”覆盖整个规划城镇；“查看整个研究范围”显示环境采样范围。规划色块不等于实际宅地，最终统计以地块节点结果为准。

## 参数与边界

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 核心选址范围 | 中心附近 300 米 | 仅用于寻找市场核心，不作为整个城镇边界 |
| 核心区尺度 | 210 米 | 独立控制防御核心的候选范围 |
| 城外街带长度 / 宽度 | 480 / 140 米 | 沿区域通路主动规划的城外建设片区 |
| 区域通路入口数 | 3 | 地图边界的可达陆路方向；可手动指定 |
| 城门数量 | 2 | 防御核心的门洞，与区域入口不再一一对应 |
| 公共院区 | 开启 | 城内教堂、城外修道院及周边聚落 |

以上为可调原型参数，不是历史城市统一尺寸。参数修改使下游过期；失败或取消不发布部分结果。设置过小的研究范围或不合适的核心、街带尺度可能无法满足布局要求，节点会报告原因。

城墙只由独立核心范围生成。改变城外街带长度不会扩大墙圈。环境中其他土地分量保留在采样与通行候选数据中，不会因为不属于核心所在片区而被删去。

## 数据结构与生成过程

为保持现有调用接口，节点结果仍叫 `SettlementLayout`，其新增 `Region: RegionalTownPlan` 是区域布局的主要数据：

- `StudyArea`：整个研究范围。
- `Districts`：核心、门外街带、机构聚落，各有边界、街道疏密和宅地模式。
- `Links`：区域通路与机构联络路的粗略路线，保存城门关联；实际路宽与坡度由道路节点验证。
- `Landscape`：田园、果园占地及其可达的规划接入路线。
- `DevelopmentArea`：所有建设片区的并集，不包括外围空白。
- `ViewBounds`：完整建设区域的观察范围。

`SettlementLayout.Town` 保存防御核心、城墙走廊、城门与公共院区。`Cells` 在区域模式下表示环境中的通行候选，不能直接当作城镇建设范围；地块节点必须使用 `Region.DevelopmentArea`。`RoutingLandArea` 和 `Area` 分别表示候选陆地面积与规划建设片区面积。

固定阶段为：核心选址 → 区域陆路目的地 → 独立防御区 → 沿区域通路规划城外街带 → 城内教堂与独立城外修道院聚落 → 田园和接入路线。修道院聚落与其他建设片区之间保留开放空间，作为独立片区生成。

道路的街巷候选覆盖全部建设片区，撤销旧版仅允许城墙内部生成次路的限制。城外机构在已生成的区域干道上寻找接入点，验证它可以不进入设防核心而到达区域出口；完整路网仍与核心相连。

宅地规则按片区变化：核心较紧凑，门外街带面宽和进深更大，机构聚落采用较疏松的尺度。每块宅地保存 `DistrictId`、城内外标记、临街道路、建筑带和后院。相交道路与广场、墙体、机构占地照常扣除。

田园在布局阶段避让区域通路预留；道路生成后，`RoadNetwork.Landscape` 再扣除实际道路占地，作为后续预览使用的数据。田园接入路线是规划数据，不代表已经生成农道模型或农业资产。

### 田园形态修订

已移除固定 100×80 米矩形、120 米等间隔扫描的田地放置方式。当前沿区域通路以不等间隔、不同侧向距离寻找田组位置，结合局部地形梯度与道路方向确定耕作方向，再按有效土地、建设片区、公共预留和道路边界裁切。田组之间保留田头或未耕作边缘，大小、方向和轮廓分别变化。

田组内部使用共享的缓弯线形表达同向条带，避免每条耕作线独立随机扭动；靠近聚落的部分候选可为果园，近水候选可为草地。用途为原型偏好，未依据土壤或洪水模拟作农学判断。默认种子得到 9 个田组/园地，其中 7 个耕作田组、2 个果园；其他种子可产生草地。

这项形态参考了 [Historic England《Field Systems》](https://historicengland.org.uk/images-books/publications/iha-field-systems/heag204-field-systems/) 对田组、条带、地形影响及浅 C / 反 S 形耕作痕迹的说明。中世纪田组本身可以较规则，因此本实现保留组内秩序，改变的是全区棋盘格排列；并不将所有田地随机切成不规则多边形。内部线条是概念性耕作标记，不是逐条建立的篱笆或产权地块。

相邻田组采用整块避让：不再裁切出绕着已生成果园或耕地的缺口。候选田组若与既有田地及其 12 米预留带冲突，就跳过该位置； 地形、道路和城镇边界仍可裁切田组。12 米是当前原型的可视分隔参数，不是历史通用值。新增检查覆盖所有田组两两间距、逻辑轮廓及最终预览三角形越界，避免仅检查面积不相交却产生叠压观感。

`LandscapeParcel` 新增 `Pattern`、`Direction` 和只读 `CultivationLines`。道路节点裁切田地后同步裁切耕作线，防止条带穿过道路、孔洞或城镇用地。三组种子的区域验证增加田组面积与方向变化、田组不重叠、耕作线裁切、固定种子复现检查，共 313 项区域检查通过。城内外宅地面积和原有路网结果保持原值。

专用截图命令 `.\tools\project.ps1 capture-landscape` 生成 `artifacts/captures/agriculture_overview.png` 、`agriculture_detail.png` 和 `agriculture_separation.png`，覆盖完整生成链、田组间隔与真实渲染。当前仍是土地与耕作纹理的几何预览，没有作物、果树或垄沟施工网格。

## 验证结果

新增 `.\tools\project.ps1 test-regional`，报告为 `artifacts/regional_validation.json`。三组种子 73129、7、22017 均检查：

- 至少两条门外街带与独立机构聚落。
- 三个区域入口与两个城门的独立关系。
- 修道院聚落和其他建设片区之间的开放间隔。
- 田园与接入路线，以及田园对最终道路的避让。
- 城外机构不经过核心仍可到达区域出口。
- 每个城外片区有实际可用宅地，实际城外宅地面积达到预设规模要求。
- 规划片区边界、墙体及机构占地约束。
- 城外参数变化不扩大城墙，固定输入可复现。

另保留 `test` 的地图、采样、布局、道路和地块检查，以及 `capture` 的控件回调、视口点选、重跑、取消、失效和实际渲染检查。视口输入测试不等同于实体鼠标键盘测试。

区域路网的新组合暴露了接触边界的孔洞归属问题。余地现从原始街区与已接受地块并集重新求差；如相接轮廓分组破坏面积账目，则作有界的 0.2 毫米接触分离，并要求修复前后面积误差不超过 0.1 平方米，否则拒绝发布。全局面积检查保持有效。固定回归数据保存在 `configs/tests/parcel_touching_boundary.json`。

2026-11-04：[道路几何定型](ROAD_GEOMETRY.md)已接入道路节点，田园、地块与路面预览共用定型占地。接触轮廓修复也检查三角化面积，并从 0.01 毫米开始逐级分离，仍要求面积变化不超过 0.1 平方米。

## 当前范围

本次完成新方案中的陆路样例：设防核心、城门外街带、独立城外机构聚落及生产景观。当前没有已知桥位输入和桥头片区生成，自动布局不虚构跨河通行；对岸环境仍保留可见。需要跨河城镇时，应下一步加入显式桥位与两岸连接契约。

城墙与农田仍为占位与区域预览；普通住宅、教堂和修道院的简化体量已接入 [05 建筑体量](BUILDING_MASSING_NODE.md)，尚未生成正式建筑、桥梁或墙体美术资产。该实现用于检查空间组织，不宣称是特定历史城镇的考古复原。

## 主要实现文件

- `scripts/pcg/regional/RegionalTown.cs`：区域输出、通路、核心与城外片区规划。
- `scripts/pcg/regional/AgriculturalLandscapePlanner.cs`：田组组织、地形方向、耕作线与田园避让。
- `scripts/pcg/regional/RegionalValidation.cs`：多种子区域验收。
- `scripts/pcg/settlement/SettlementLayout.cs`：节点入口、结果与兼容调用。
- `scripts/pcg/roads/RoadGenerator.cs`：跨片区街巷、城门与机构连接。
- `scripts/pcg/parcels/ParcelGenerator.cs`：按片区生成地块与面积账目。
- `scripts/pcg/preview/SettlementPreview.cs` / `MedievalPreview.cs`：区域、设施及田园预览。
