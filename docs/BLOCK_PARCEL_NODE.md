## 使用

依次生成环境采样、聚落布局、道路及 03B 道路竖向，在右上选择 **04 街区与地块**，点击“独立生成地块”。生成不重建上游，也不生成建筑。参数在当前运行会话中有效。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 目标面宽 / 进深 | 14 / 24 米 | 沿道路边界划分条带，向街区内部延伸；面宽有种子控制的小幅变化 |
| 最小面积 | 80 平方米 | 小于该面积的候选不生成地块 |
| 最小临街长度 | 6 米 | 至少一段连续、真实共享的临街边达到此长度 |
| 道路退界 | 2 米 | 建筑范围避让道路占地外扩区域 |
| 侧后退界 | 1 米 | 地块轮廓向内收缩；临街一侧同时遵守道路退界，取更严格结果 |
| 商业 / 生产目标 | 20% / 10% | 以地块面积为目标，核心附近优先商业、外围优先生产，剩余住宅 |
| 种子 | 73129 | 控制临街分段的小幅变化和同分顺序，固定输入可复现 |

用途按完整地块分配，实际面积比例会有偏差，面板显示实际值。首版尚未加入人工用途区域绘制。地块进深是沿临街边法线的目标范围，不保证每块都是完整矩形。

## 生成过程

1. 将聚落 `Included` 单元合并为真实多边形区域，保留孔洞。按照聚落约定，将 `Reserved` 单元形成广场预留区。
2. 合并道路 `Footprint` 的全部路带、转角和路口，占地重叠只扣一次。用聚落区域减去道路与广场的并集。
3. 将剩余区域的每个连通多边形识别为一个街区，包括道路环路内街区与城市外围片区。街区数量不等于道路闭合回路数量。
4. 在街区轮廓上识别与道路占地实际相邻的边界，并建立道路边 ID 引用。临街判定检查真实共享边，不能只凭离道路较近。
5. 按目标面宽切分临街边，向内生成目标进深条带，再与尚未分配的街区部分求交。每次只扣除通过检查的地块，防止角部和不同方向条带重叠。
6. 检查面积、连续临街长度与最低进深条件；向内偏移地块边界，并扣除道路退界区域，形成可建筑范围。可建筑范围小于 20 平方米时跳过候选。
7. 按距核心位置和面积目标分配用途，输出地形范围、剩余空地与原因，核对面积账目后一次发布。

地块分割使用多边形运算，而非把道路加粗成一圈环境网格。当前环境限制仍然继承采样精度；细分地块不增加地形信息。内部采用固定点坐标运算以减少重复裁切误差，其数值精度不代表地形实测精度。

无临街边、尺寸不足、退界后空间不足以及超出目标进深的土地保留为剩余空地。不强行填满街区，不给内部孤立地块伪造道路通达性。没有地块满足条件时，可发布包含街区和剩余空地的结果，并在面板提示。

## 输出 `ParcelLayout`

| 数据 | 内容 |
| --- | --- |
| 输入与版本 | 当前 `RoadNetwork`、道路结果修订号、参数快照；通过道路绑定同版环境与聚落 |
| `Blocks` | 街区 ID、带孔洞的二维区域 |
| `Parcels` | 地块 ID、所属街区、用途、地块轮廓、可建筑范围 |
| `Frontage` | 一个或多个真实临街线段，包含道路边 ID、端点与长度 |
| 地形统计 | 涉及采样单元的最大坡度、保守高程范围 |
| `Remainders` | 剩余空地区域、所属街区与未分配原因 |
| 面积摘要 | 街区土地面积、已分配地块面积、剩余面积 |

`ParcelRegion` 持有只读边界环与处理孔洞后的三角形，可用于预览；内部多边形数据不暴露可写引用。可建筑范围可能包含多个分离区域，建筑节点应选取实际能够容纳建筑的一块，不能只用总面积判断建筑可放置。

建筑节点应使用 `Buildable` 检查实际占地，依据 `Frontage` 确定朝向，再检查细部高差。当前结果没有生成建筑、碰撞或导航。未来道路形状定稿改变占地后，必须使本节点及建筑结果过期并重新生成。

## 可视化

| 图层 | 内容 |
| --- | --- |
| 街区边界 | 每个连通街区不同底色，显示外轮廓及内部孔洞 |
| 地块与用途 | 住宅绿、商业黄、生产紫，显示地块边界 |
| 可建筑范围 / 退界 | 青绿填充可建筑范围，同时保留地块外轮廓 |
| 剩余空地 | 橙色显示未分配土地 |

道路作为背景显示。点击地块会高亮其临街边，显示所属街区、用途、道路引用、高程范围与可建筑面积；悬停显示地块面积、临街长度与坡度。切换图层和选中地块不触发生成。

修改参数使本节点过期；道路重跑或上游变化传播失效。取消、失败和生成期间输入变化均不发布部分结果，旧结果保留并明确标记。

- `scripts/pcg/parcels/ParcelLayout.cs`：几何运算封装、带孔洞区域、只读数据与参数。
- `scripts/pcg/parcels/ParcelGenerator.cs`：街区提取、临街划分、退界、用途、面积账目与节点生命周期。
