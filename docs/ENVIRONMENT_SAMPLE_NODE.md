# 第一个节点：环境采样

更新日期：2026-11-03  
状态：首版已实现并接入测试地图。所属框架：[简单节点式 PCG 框架](PCG_FRAMEWORK_DESIGN.md)。

## 使用与实现状态

运行 `.\tools\project.ps1 run`，在右侧“环境采样”面板点击“独立运行采样”。地图在启动时于管线外准备，采样按钮只读取当前地图。参数包括范围中心、宽深、间距、坡度阈值和植被读取开关；“取当前地图范围”将当前地图矩形写入参数。

采样过程中支持取消并锁定输入参数；完成后可切换六种结果图层、显示网格、筛选限制原因和悬停读取单元数据。地图或参数变化将旧结果标为过期，`Main.SampledEnvironment` 只提供有效结果。预览可继续查看旧快照。界面参数不自动保存；默认配置为 `configs/environment_sample.tres`。

```powershell
.\tools\project.ps1 sample          # 无界面准备测试地图，再单独运行节点；写出摘要
.\tools\project.ps1 test-sampling   # 验证节点与测试地图适配
.\tools\project.ps1 test            # 地图原有检查 + 环境采样检查
.\tools\project.ps1 capture         # 引擎内交互检查与实际渲染截图
```

数据摘要写入 `artifacts/environment_sample.json`；验证报告写入 `artifacts/environment_validation.json`。摘要不是完整采样结果的磁盘缓存，完整只读结果保存在节点内存中。截图位于 `artifacts/captures/sampling_*.png`。

本次交付为可独立调用的单个高层节点，未实现通用图编排器或图编辑器。输入支持无孔、无自交的简单多边形；尚未加入场景障碍自动识别。默认 10 米网格用于宏观判断，水域仍按四角与中心采样，不能证明细小水道或连续边界无遗漏。

## 1. 职责与边界

**把预设环境中指定区域的数据，采样成城镇生成模块可独立使用的只读快照。**

节点回答：地面在哪里、有多陡、哪里有水、哪里已有明确障碍或禁建限制。它提供环境事实和基础建设限制，供聚落布局、道路生成、街区与地块、建筑生成节点分别使用，接入 [一次性节点生成工作流](PCG_FRAMEWORK_DESIGN.md)。

基础地图由管线外准备。采样节点不创建地形、河流或自然植被，不选聚落位置，不规划道路，也不计算人口、用途或交通带来的动态适宜性。图上始终只有一个“环境采样”节点，其内部读取、采样、约束整理和检查都用 C# 完成。

```text
外部预设环境的只读查询源
    + 节点参数：范围、间距、基础坡度限制
                    ↓
                 环境采样
                    ↓
       CityEnvironmentData（一个输出端口）
```

## 2. 输入与参数

### 一个显式外部输入

输入名 `environment_source`，接口为 `IEnvironmentSource`。宿主把准备好的环境绑定给节点；运行节点不会触发外部地图生成。

| 输入内容 | 含义 |
| --- | --- |
| 来源 ID、修订号 | 标识本次读取的环境版本，地图与环境标记变化时由宿主更新 |
| 有效覆盖范围 | 判断指定位置是否存在可查询的地面 |
| 点查询 | 地面高度、坡度、水域状态；植被密度按来源能力提供 |
| 静态约束 | 已标记的禁建区、保留物或已有占地的二维轮廓 |
| 数据层状态 | 明确哪些层已提供、已确认为空、尚未提供 |

适配器负责将不同环境来源转成同一套语义。首版只适配现有测试地图，不提前实现场景碰撞扫描或通用地形插件支持。

坐标沿用项目约定：X 向东、Z 向南、Y 向上，单位为米。输入适配器负责世界坐标转换；首版处理单层地表，不表达桥上、桥下或洞穴等多层可行走表面。

### 参数面板

| 参数 | 首版值或规则 | 作用 |
| --- | --- | --- |
| 采样范围 | 初始取当前地图范围：X/Z 为 -1000 至 1000 米；保存为明确矩形 | 指定城镇研究区域，可缩小到局部，不随地图替换静默改变 |
| 目标采样间距 | 默认 10 米，大于 0 | 控制数据量和宏观细节，显示实际生成的网格间距 |
| 普通地面建设最大坡度 | 暂定 12°，允许 0–90° | 生成基础候选区域；这是可调原型参数，尚无形态验证结论 |
| 读取植被密度 | 默认开启；来源没有此层时显示未提供 | 给后续清理成本或景观避让评分提供事实数据 |

“取当前地图范围”是一次参数赋值操作。预览图层、透明度和网格显示不属于计算参数。

首版没有地图种子、起伏强度、河宽、森林生成密度、河岸退让距离或综合适宜性权重。采样不使用随机数；河岸退让需要可靠的岸线语义，留待有明确数据来源时增加。

## 3. 采样哪些数据

| 数据层 | 首版语义 | 缺失时处理 |
| --- | --- | --- |
| 地面高度 | 地表高度；水域中为水下地面，不是水面高度 | 来源完全不支持时失败；局部无地面则标记无效 |
| 坡度 | 来源提供的地面坡度，单位为度 | 来源完全不支持时失败；局部缺失则不能判定该处候选状态 |
| 水域 | 来源明确标识该位置是否为水域 | 来源完全不支持时失败；局部未知不能当作陆地 |
| 植被密度 | 0–1 的环境密度场，保留来源含义 | 允许未提供，不能把未知显示成零密度 |
| 禁建区 | 外部明确标记的禁止普通建设的二维范围 | 未提供与确认没有禁建区分开表达 |
| 固定障碍 | 外部标记为需要保留的建筑、岩石等占地轮廓 | 未提供与确认没有固定障碍分开表达 |

地面高度、坡度和水域是基础必需层。禁建区、固定障碍可以由宿主明确声明为空；若尚未提供，其未知状态必须保留，不能据此批准建设。植被是可选的软信息，不因为林地密度高就自动禁止建设。

自然树木默认属于植被信息。需要保留和精确避让的树木，应由外部输入额外标记为固定障碍；密度场不代表单棵树的轮廓。

来源层状态采用三种即可：`Provided`、`KnownEmpty`、`Unavailable`。`KnownEmpty` 只适用于水域、植被或约束等允许为空的层，不能用于地面高度和坡度。局部采样缺失另用样本有效标记记录。

## 4. 数据组织与采样规则

### 规则网格

首版使用与世界 X/Z 轴对齐的矩形网格。设范围宽、高为 W、D，目标间距为 S：

```text
CellsX = ceil(W / S)
CellsZ = ceil(D / S)
StepX  = W / CellsX
StepZ  = D / CellsZ
```

这样范围保持不变，实际间距不大于目标值。网格顶点数为 `(CellsX + 1) × (CellsZ + 1)`，每个单元额外查询一次中心位置，降低只检查四角造成的漏采。

2 × 2 公里、10 米间距对应 200 × 200 个单元、40,401 个顶点和 40,000 个中心位置，共 80,401 次点查询。这是查询次数的设计值，不是性能实测。

遍历顺序固定为 Z 外层、X 内层。顶点索引为 `z * (CellsX + 1) + x`，单元索引为 `z * CellsX + x`。所有点采用同一来源版本。

### 单元汇总

内部对每个单元汇总四角与中心共五个位置：

- 顶点高度用于查询和地形调试显示；中心高度用于诊断，不覆盖顶点高度。
- 单元坡度取五点中已知坡度的最大值，并记录是否存在未知值。
- 任意已知采样点是水域，就记录该单元包含水域。全部已知且为陆地时才记录采样点均为陆地。
- 植被密度使用中心采样值，未知时保留未知标记。
- 禁建区、固定障碍使用二维轮廓与整个单元矩形做相交判断，边界接触也算相交；不能只看五个点是否落入轮廓。

规则网格和五点检查是宏观近似。小于采样间距的窄水道或陡坎仍可能漏采，单元候选状态不是整块土地绝对可建的证明。后续道路和地块落实时需要更细的数据及几何检查；精确水域边界支持属于后续明确扩展，不隐含为首版已具备能力。

### 越界与无效值

先检查覆盖范围再查询。范围外、无地面或必要字段未知的样本保留为无效，不调用会夹取边界的查询来伪造有效结果。若整个区域没有有效基础样本，本次运行失败；部分无效可以输出并显示覆盖缺口。

来源声称有效、却返回非有限高度或越界的坡度/密度时，视为输入错误，报告位置与字段并终止本次运行，不静默修正。参数必须有限，矩形尺寸必须为正，分配数组前校验网格计数并检查预设查询预算；过密采样应提示缩小范围或增大间距。

## 5. 基础建设限制

输出限制原因，而不只输出一个混合的 0–1 分数。

| 原因标记 | 触发条件 |
| --- | --- |
| `NoGroundData` | 单元所需位置没有有效地面 |
| `UnknownLayer` | 必需判定信息缺失，包括坡度、水域或未提供的禁建/障碍层 |
| `Water` | 单元采样位置中发现水域 |
| `TooSteep` | 已知采样坡度最大值大于配置阈值 |
| `NoBuildZone` | 单元与禁建轮廓相交 |
| `Occupied` | 单元与固定障碍轮廓相交 |

一个单元可同时包含多个原因。根据原因得到三种状态：

1. **受限 `Blocked`**：发现任一明确限制：水域、坡度超限、禁建区或固定障碍。其他未知原因仍保留。
2. **未知 `Unknown`**：没有明确限制，但地面或约束信息不完整。
3. **候选 `Candidate`**：所需信息完整，且当前采样精度下没有发现上述限制。

该状态只表达**普通地面建设的基础候选区域**。它不等同于道路通行性，不代表桥梁、码头等特殊设施的许可，也不决定住宅、商业或作坊的用途偏好。下游可以利用原始数据应用自己的业务规则；不得把 `Unknown` 当作已确认候选。

首版不输出 `Suitability` 综合分。后续选址模块自行组合坡度、植被、道路、核心吸引力和需求等因素。

## 6. 一个输出对象

输出端口名 `environment`，类型 `CityEnvironmentData`。以下是字段分组，实际代码可使用私有数组与只读查询，不要求逐项建立独立框架类。

| 分组 | 内容 |
| --- | --- |
| 来源与配置 | 来源 ID、修订号、采样参数快照、数据层状态、可用时记录来源原生分辨率 |
| 网格描述 | 世界范围、单元数量、实际 X/Z 间距 |
| 地表样本 | 顶点高度及有效标记 |
| 单元数据 | 最大采样坡度、水域状态、植被密度与有效标记、限制原因、基础候选状态 |
| 静态约束 | 只读禁建和固定障碍轮廓副本，保留来源标识，供下游进一步检查 |
| 摘要 | 有效覆盖、高程范围、受限/未知/候选单元面积、原因分布及本次采样诊断 |

同一单元可能有多个限制原因，因此各原因面积不能直接相加；三种互斥状态的面积总和应等于采样矩形面积。

建议公开三个主要查询：

```csharp
bool Contains(Vector2 worldXZ);
bool TryGetCell(Vector2 worldXZ, out EnvironmentCell cell);
bool TryHeightAt(Vector2 worldXZ, out float height);
```

`TryGetCell` 在范围内返回单元及其状态，单元为 `Unknown` 不等于查询失败；范围外返回 false。最大 X/Z 边界归属最后一个单元，不越界索引，也不对范围外位置进行夹取。

`TryHeightAt` 在采样网格上做固定三角形线性插值，沿用当前地图网格的三角形划分方向。参与插值的顶点有无效数据时返回 false。它查询的是采样近似地面，不保证与原地图每个位置完全一致；特别是岸坡，不能把 10 米采样当作精确建筑落地数据。

布尔、分类与限制原因不做连续插值。结果拥有自己的数组和轮廓副本，不保留实时场景引用或查询源回调；地图后来变化不改变旧快照内容，只使它过期。

## 7. 节点内部实现

业务代码提供同步入口 `EnvironmentSampler.Sample(source, options)` 和支持进度/取消的异步入口：

```csharp
Task<CityEnvironmentData> SampleAsync(
    IEnvironmentSource source,
    EnvironmentSampleOptions settings,
    PcgContext context);
```

内部顺序固定即可：

1. 校验输入绑定、层能力、参数与网格预算，固定来源版本。
2. 复制静态约束轮廓，准备顶点及单元数组。
3. 查询网格顶点、查询单元中心，记录有效性。
4. 汇总单元数据，对约束轮廓做栅格化，生成限制原因和三种状态。
5. 计算摘要并检查数组尺寸、数值范围和状态一致性。
6. 再确认来源版本未变，发布完整只读结果。

节点适配层只负责输入与参数绑定。查询循环、轮廓相交、汇总和校验留在 `EnvironmentSampler` 等内部普通 C# 代码里，不拆成图节点。

按行提供进度和取消检查。来源替换、计算失败或取消时不发布部分结果；旧快照按框架规则保留为过期预览。具体线程安排沿用框架的首版顺序执行策略，不在此节点另建调度器。

环境来源、来源修订号或采样参数变化会让本节点与下游过期。城镇种子、节点画布位置、相机和显示开关变化不使本节点过期。

## 8. 当前测试地图的适配

当前源码提供以下能力：

| 现有接口/字段 | 接入方式 |
| --- | --- |
| `TemperateMapData.Contains` | 在读取前检查点是否在地图内 |
| `Sample().Height` | 顶点与中心的地面高度 |
| `Sample().SlopeDegrees` | 已有坡度场的采样值，保持其来源精度含义 |
| `Sample().IsWater` | 当前测试地图的水域判定 |
| `Sample().Forest` | 植被密度场；不是树冠实际覆盖率或单棵树占地 |
| `Spacing` | 记录来源原生网格间距，默认约 5.21 米 |
| `Sample().Suitability` | 不导入标准输出，避免继承测试地图里混合的评分规则 |
| `Sample().RiverDistance` | 是距河流中心线距离；首版不作为距岸距离输出 |

现有 `TemperateMapData` 没有禁建区或固定障碍轮廓接口，也没有来源修订号。首版宿主适配器补充显式的约束列表和修订号。在当前只含自然地形、河流和普通植被的测试场景中，可以明确配置两个已知为空的约束列表；换成其他地图时必须重新确认，不能沿用默认空列表冒充已检查。

`Main.Generate()` 继续在管线外创建测试地图。准备好地图后，宿主创建只读查询适配器并绑定给采样节点。节点执行中不调用 `new TemperateMapData(...)`，不修改 `MapSettings`，也不改动已有树木或地形。

若需要独立编辑禁建区，宿主更新约束列表和统一来源修订号即可，不需要重新生成基础地图。

## 9. 节点预览

节点卡片显示“环境采样”、有效/过期/失败状态、单元尺寸、有效覆盖和耗时。参数区显示外部环境来源与版本，以及范围、目标间距、坡度阈值、植被读取开关。

结果区在现有地图上叠加：

- 采样边界与可切换的网格线。
- 高程、最大采样坡度、水域、植被密度图层。
- 基础建设状态：候选为绿色、受限为红色、未知为灰色；水域图层单独用蓝色。
- 指定限制原因，例如仅查看坡度超限或禁建区。

悬停显示坐标、单元索引、采样高度、坡度、水域、植被、全部限制原因和状态。缺失字段显示“未知”，不显示为 0。摘要列出有效覆盖、候选面积和未知面积；部分数据缺失时，用户能看到缺的是哪一层。

重跑只替换采样叠加结果，已有地图继续由外部渲染器显示。旧结果仍可查看，但明确显示来源版本及“已过期”。

## 10. 首版交付与验收

实现范围：节点参数与数据类型、采样业务代码、现有地图查询适配器、一个调试预览器。由框架负责运行入口和缓存状态；本节点不增加独立流程编辑功能。

验证使用小型可解析的环境查询源，以及现有测试地图。已覆盖以下验收项：

| 场景 | 验收结果 |
| --- | --- |
| 平地，无水域，两个约束层已确认空 | 覆盖内单元为候选，高度一致 |
| 固定斜坡，坡度位于阈值两侧及恰等于阈值 | 仅大于阈值时产生坡度限制 |
| 五个检测点覆盖到的水域 | 对应单元有 `Water` 原因 |
| 窄禁建/障碍轮廓穿过单元但避开采样点 | 通过轮廓相交仍可标为受限 |
| 禁建层未提供与已确认空 | 前者产生未知状态；后者参与正常候选判断 |
