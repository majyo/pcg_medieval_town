# 温带平原测试地图

当前主场景运行时生成一张 2 × 2 公里的三维区域地图，包含长程缓坡、贯穿区域的曲流和简模森林。地形用于后续聚落布局、道路、地块与建筑的一次性节点生成测试；当前阶段未放置城市、道路或建筑。

## 默认地图

| 项目 | 默认配置或实测结果 |
| --- | --- |
| 随机种子 | 73129 |
| 区域范围 | X、Z 均为 -1000 至 1000 米 |
| 地形网格 | 384 × 384 个单元，148,225 个顶点，采样间距约 5.21 米 |
| 高程范围 | 约 2.15 至 50.22 米，包含河床；显示采用真实米制尺度 |
| 河道 | 中心线约 2.49 公里，名义宽度 48 米，沿程变化 |
| 河面 | 从北侧的 14 米连续下降到南侧的 6 米 |
| 森林 | 3,533 株简模树木，以阔叶树为主，混合少量针叶树 |
| 林地区域 | 约占全图 38%，按森林密度场大于 0.24 统计，不等于树冠覆盖率 |
| 开阔缓坡 | 约占全图 45%，要求非水域、坡度小于 5°、森林密度小于 0.24、适宜性大于 0.55 |

主起伏来自低频噪声与宽缓波形，附加的小尺度高差幅度较小。河流先生成平滑中心线与下游水位，再切出河床、岸坡和谷地；这是可控的测试地形生成方法，尚未加入降雨汇流或侵蚀模拟。

森林由大尺度斑块、噪声边界和中央空地区域共同决定。树木采用三种共享简模，通过 MultiMesh 批量绘制；分布避开水域、近河岸和陡坡。森林分布数据与是否显示树木相互独立。

## 运行与操作

使用 Godot 4.7.2 .NET 打开项目，构建 C# 后按 F5，或在项目目录运行：

```powershell
.\tools\project.ps1 run
```

| 操作 | 功能 |
| --- | --- |
| W / A / S / D、中键拖动 | 平移观察位置 |
| 鼠标滚轮 | 缩放 |
| 右键拖动 | 调整朝向与俯仰角 |
| Q / E | 旋转朝向 |
| Home、复位视角 | 回到默认全图视角 |
| 正俯视 | 接近垂直的俯视图 |
| 地图种子、重建地图 | 生成另一组可复现的地图；种子输入框不会自动保存到配置 |
| 观察图层 | 切换自然景观、高程、坡度和建设适宜性 |
| 森林、河面开关 | 控制显示，关闭河面可观察河床 |
| 鼠标悬停地形 | 在底栏读取坐标、高程、坡度、用途倾向和适宜性 |

切换到诊断图层时默认隐藏树木，可通过森林开关重新显示。建设适宜性是坡度、河岸退让和林地清理成本的启发式评分，尚未纳入道路可达性或用途配置。

## 参数与后续接入

此地图作为城镇 PCG 的外部预设环境使用，地图生成与绘制在城镇管线外运行。已接入 [环境采样节点](ENVIRONMENT_SAMPLE_NODE.md)，读取指定城镇范围的数据并输出独立的只读结果；节点本身不生成地形、河流或自然植被。使用右侧面板独立运行、取消和预览，地图重建后旧采样结果过期。

配置文件为 `configs/temperate_plain.tres`，可在 Godot Inspector 中调整种子、地图尺寸、采样数、起伏强度、河宽、森林密度和树木间距。改变配置后重新运行主场景。

| 文件 | 职责 |
| --- | --- |
| `scripts/terrain/MapSettings.cs` | 可导出的地图参数与有效范围 |
| `scripts/terrain/TemperateMapData.cs` | 管线外测试地图的生成与查询，供环境采样适配器读取 |
| `scripts/terrain/MapRenderer.cs` | 地形网格、河面、简模树木和诊断颜色 |
| `scripts/MapCamera.cs` | 区域观察相机 |
| `scripts/Main.cs` | 场景装配、参数界面和悬停信息 |
| `scripts/terrain/MapValidation.cs` | 无图形界面的地形验证入口 |

坐标约定：X 向东、Z 向南、Y 向上，1 个世界单位等于 1 米。北方为 -Z，河流从 -Z 边界流向 +Z 边界。

通过 `TemperateMapData.Sample(new Vector2(x, z))` 查询高程、坡度、水域、森林密度、建设适宜性和距河中心线距离。越界查询会抛出异常，应先调用 `Contains`。`HeightAt` 与渲染网格的三角形插值一致，边界外会夹取到边界。

`Heights`、`Slopes`、`Water`、`Forest`、`Suitability` 数组按 `z * Side + x` 排列，生成后按只读数据使用。河流中心线和树木位置分别保存在 `River`、`Trees`；隐藏显示不会修改这些数据。主场景的 `EnvironmentData` 属性提供当前原始地图数据，由 `TemperateEnvironmentSource` 适配为采样节点的外部查询源；后续城建模块消费 `SampledEnvironment` 中当前有效的只读采样结果。

当前地图在运行时从配置重建，未烘焙成静态场景，也未生成物理碰撞体。城市布局与地面贴合可先使用环境查询接口。

## 验证

```powershell
.\tools\project.ps1 test
.\tools\project.ps1 capture
```

`test` 检查三组种子、固定种子精确复现、河道栅格贯通、下游水位下降、树木落地且不进入水域、开阔平原比例、越界查询以及森林密度为零的情况。结果写入 `artifacts/map_validation.json`。

`capture` 先通过 Godot 输入分发验证按钮、缩放、旋转、平移、显示开关、图层回调、种子重建和 Home 复位，再使用真实渲染窗口输出全图、河流森林近景、坡度、适宜性及隐藏河面的高程图，写入 `artifacts/captures` 后退出。
