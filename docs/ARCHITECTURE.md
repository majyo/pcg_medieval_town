# 架构

## 1. 结构

```
scripts/
  Main.cs              组合入口：地图、管线、预览、面板；--test / --capture
  Town.cs              管线的阶段顺序
  Checks.cs            无界面检查：每阶段的不变量 + 可复现性
  core/
    Pipeline.cs        线性管线、阶段基类、状态与失效
    Region.cs          唯一的平面多边形类型（封装 Clipper2）
    ParamAttribute.cs  标记可在界面编辑的参数
  stages/              五个阶段：选项、结果类型和算法各在一个文件里
  view/                CityView（统一预览）、StagePanel（自动参数面板）、MeshKit
  terrain/             基础地图数据（TemperateMapData）与地形渲染
```

依赖方向只有一个：`stages` 只依赖 `core` 和地图数据；`view` 读取阶段结果；`Main` 把它们组合起来。阶段代码不引用任何 Godot 节点。

## 2. 管线

- 阶段是纯函数：`Run(地图 + 上游结果, 选项) → 结果`。同样的输入必然得到同样的结果。
- 管线是线性的。修改第 i 个阶段的参数，第 i 个阶段及之后的阶段都变为“已过期”。
- 每次运行先复制一份选项，界面可以随时修改正在使用的选项对象。
- 阶段在后台线程运行；取消或失败时不发布结果，下游保持过期。
- 上游结果通过 `inputs.Get<T>()` 按类型读取。

新增参数：在选项类里加一个带 `[Param]` 的属性。面板控件、过期处理和复制都会自动生效。

## 3. 阶段

| 阶段 | 结果 | 内容 |
| --- | --- | --- |
| 01 场地分析 | `Site` | 覆盖全图的规则网格（默认 8 m）：高程、坡度、适宜性，以及不可建设的原因（水域、河岸退让、坡度、森林） |
| 02 城镇布局 | `TownLayout` | 选择核心位置（可建设土地多、靠河但不在河上、接近地图中部）；方形广场；沿射线遇到不可建设土地就收缩的星形城墙；朝向开阔地的城门，每座城门对应一个地图边缘入口 |
| 03 路网 | `RoadGraph` | 在场地网格上做 A\*：城门→广场的主街，城门→地图边缘的城外道路，城内按间距撒点后用最近点对加少量成环连接的街巷。先标记网格连线，再从连线中提取节点和路段，不需要线段求交 |
| 04 街区与地块 | `ParcelSet` | 可建区 = 城墙内退让 − 道路占地 − 不可建设格；沿每条街两侧按面宽切出进深固定的临街地块，先主街后街巷，后切的地块扣除已占用的部分 |
| 05 建筑 | `BuildingSet` | 每个地块临街放一栋矩形房屋，层数随机，主街加一层；双坡屋顶，窄长房屋山墙朝街；偶尔留出小巷 |

## 4. 不变量

`tools/project.ps1 test` 对种子 73129、7、22017 跑完整条链，检查：

- 场地：可建设比例在合理范围内。
- 布局：核心可建设；广场在城墙内；至少一座城门，城门在城墙上。
- 路网：引用有效，没有零长度路段，全部连通，城门全部接入；道路不进水域；城内道路只在城门处穿过城墙。
- 地块：在可建区内，不压道路，互不重叠。
- 建筑：在各自地块内，互不重叠，高度有效。
- 同一种子生成两次，结果相同。

## 5. 加功能的规则

1. **先广后深。** 整条链在三个种子下都“看起来对”，才加深某一个阶段。
2. **一次只加深一个阶段。** 需要改上游输出时，先改上游结果类型并跑检查，再继续。
3. **每个新功能附带一条不变量**，写进 `Checks.Invariants`，不另建验证脚本或命令行开关。
4. **展示细节放到最后。** 门窗、材质、植被、LOD 等，等生成结果稳定后再做。
5. **代码格式由 `.editorconfig` 约束：** 一行一条语句，单行不超过 140 字符，提交前执行 `dotnet format whitespace`。

## 6. 已知局限与后续方向

- 没有桥：城门朝河时，城外道路无法到达地图边缘，会给出提示。
- 道路贴着原地形，没有纵断面或地形修整。如果以后要做，用“叠加高度场”实现，不复制地形数据。
- 地块只有临街一种类型，街区深处留作后院，没有公共建筑（教堂、市政厅）和城外街带。
- 场地分析约 1.8 秒（每格都在查最近河段），其余阶段合计不到 0.2 秒。

建议的加深顺序：路网形态 → 街区与地块形态 → 公共建筑与建筑类型 → 城外街带与桥 → 地形修整 → 视觉细节。
