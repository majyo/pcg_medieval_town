# 道路系统三阶段设计

日期：2026-11-08。状态：**设计稿，尚未实施**。

本方案依据本次重新确认的需求编写，替代旧道路施工方案和五项收尾计划作为后续道路工作的设计依据。旧代码与旧验收记录不代表本方案已实现。

## 1. 目标与范围

目标：生成连通、有宽度和主次层级、顺应大地形且表面平顺的道路；优先控制实现复杂度、生成开销和运行开销。

采用三个独立阶段：

```text
原始地形 + 环境约束 + 聚落布局
              ↓
       03 道路规划
       路网、道路目标表面、地形修改计划、规划验证
              ↓
       03B 道路占地地形平整
       应用修改计划，生成修整地形及显示网格
              ↓
       03C 道路生成
       生成道路覆盖纹理，在修整地形上显示道路
```

第一阶段负责所有道路有效性检查。第二、第三阶段暂不增加独立的几何复验、自动修复或验收流程。运行取消、输入版本绑定和资源创建失败处理属于生命周期管理，不是重新验证道路。

### 本次包含

- 区域入口、城门、核心及广场的路网连接；主次道路、交叉口与明确占地。
- 消除道路短距离颠簸，横向平整，路段与平台连续。
- 修改道路占地内的地形，以及明确范围内的窄边缘过渡。
- 用简单地形材质表达道路，维持同一份占地与高度数据。
- 结果可复现、任务可取消、失败原因明确、计算量有上限。

### 本次不包含

- 建筑入口、台阶、基础、建筑保留率等衔接改造。
- 碰撞、导航、角色行走验证、交通模拟。
- 路拱、排水沟、路缘石、挡土墙、桥梁、隧道、深路堑结构。
- 外部美术资源、高精度铺装、车辙和装饰。
- 植被清理与重新落地、城墙基础调整。

地形修改仅重新纳入本次明确的道路整平范围，不恢复旧施工系统的全部土方与城市衔接工作。可能出现较大的挖填量、过渡带较陡或已有物体与新地形不贴合，这些限制应如实保留。

## 2. 表现方案：地形本身作为路面

选择 **局部地形整平 + 道路覆盖纹理 + 现有地形着色器**。

| 方案 | 优点 | 代价与结论 |
| --- | --- | --- |
| 独立几何道路 | 路面几何独立，便于后续制作厚度和路缘 | 需要维护地形与道路两套表面；当前范围不需要，首版不采用 |
| 地形材质道路 | 路面就是整平地形，只有一套高度和可见表面 | 必须有足够的局部地形网格精度；本方案采用 |

“纹理道路”只负责标出道路范围和基础颜色，不用纹理代替整平。不使用透明覆盖平面、贴花节点或顶点位移着色器。

当前仓库依据：

- `scripts/terrain/MapRenderer.Graded.cs` 已支持挖除被替换的原生地形面、局部细分和分组显示；现有细分数为 10。
- `shaders/terrain.gdshader` 已有地形材质和修整掩膜混合，可加入独立道路覆盖通道。
- `GradedTerrain.BedHeightAt` 仍包含为独立路面让位的压低处理；新模式取消该语义。
- `RoadSceneBuilder` 仍生成近远两套独立路面，并包含裁切、细分和设计高度查询；新模式不进入这条路径。
- `project.godot` 使用 Compatibility 渲染器；方案沿用现有普通地形网格和材质接口。

以上是可复用接口的核对，不是新方案的性能实测或完成声明。

## 3. 第一阶段：道路规划

### 3.1 输入和固定约束

输入为原始地形只读接口、环境约束、聚落布局和道路参数。规划始终读取原始地形，不读取上一次道路整平结果，避免重复运行累计修改。

入口、核心、城门位置由上游确定，规划不为消除失败而移动它们。广场允许道路通行，水域及其他明确禁改区域保持原状。合法性检查覆盖整个路宽与实际地形处理范围，不只检查中心线。

### 3.2 路网与平面定型

优先复用现有主路连接、次路候选、交叉拆分、重合去重、占地并集和来源边界。

- 主路连接所有必需锚点；次路仅保留接入主路的部分。
- 路段、路口、广场划为内部不重叠的面片，共用边界顶点。
- 广场优先拥有广场内的表面；路口拥有分支交汇区域；路段在平台边界终止。
- 普通转角用有限截面描述，急弯削角；不强制为每个折点拟合解析曲线。
- 平面定型不能制造新接触、折叠、无效宽度或越界；不能通过的必需路段报告失败。
- 保留现有道路 ID 和临街边界契约，但不新增建筑生成需求。

### 3.3 道路目标高度

使用局部纵断面和平面平台，不使用全城联合优化、ADMM 或独立科学计算运行环境。

1. **平台高度**：路口、广场取各自覆盖区域原始地形采样的平均高度，首版采用水平平台；边界入口保持规定的接入高度。相邻平台相交时在平面阶段合并，冲突的固定高度直接失败。
2. **路段采样**：沿扣除平台后的中心线按固定步长采样原始地形，并补入端点与转角；端点高程取所属平台。
3. **长程趋势**：用固定长度的滑动平均过滤原始高度，使用前缀和一次计算。平滑长度是沿道路的实际距离，不能用固定点数替代。
4. **两端接顺**：以有界长度的三次 Hermite 过渡连接平台和中部趋势，平台端导数为零，中部导数取趋势曲线导数。两端过渡相遇时，整个短路段改为一段端点导数为零的 Hermite 曲线。
5. **中段插值**：趋势采样之间采用限制过冲的分段三次 Hermite 插值；共享站点导数，避免每个采样点出现坡度跳变。
6. **横断面**：每个道路截面左右同高。相邻截面连接为带状三角面；平台按平面三角化，接缝顶点直接共用。

每条路只计算一次候选纵断面。完成后若坡度或平顺性不合格，第一阶段返回路段、位置和原因；不自动放宽阈值、不反复改变平滑尺度，也不自动重选城市核心。

该算法是低成本启发式，不能保证找到所有理论上可行的道路。报告应区分“本次候选不合格”和“几何不可达”，不把前者描述成数学上的无解。

### 3.4 先离散，再验证

第一阶段同时确定局部地形的网格拓扑与最终目标顶点高度。第二阶段不能再进行自适应细分、减面或高度混合，否则第一阶段检查的对象会被改变。

- 原生地形单元是最小替换单位；仅将道路和过渡带涉及的原生单元加入计划。
- 被替换单元统一细分，初始建议细分数 8；原生约 5.21 m 间距对应约 0.65 m。实际步长从输入地形取得，不硬编码地图尺寸。
- 细分数由原生间距和最窄道路共同确定，原则是路宽内至少约四个网格间隔。首版设置上限，所需精度超限时规划失败，不静默生成过粗路面。
- 相邻细单元共用全局整数格点和高度；三角形方向沿用原生地形对角线。
- 道路覆盖三角形涉及的全部网格顶点都要安排目标高度，包括边界外一圈必要支撑顶点。支撑区属于整平范围，不属于可见道路占地。
- 若某个网格单元同时跨越彼此独立的道路表面、窄间隙或禁改区域，规划检查其插值是否可接受；不合格就报告精度/空间冲突，不按道路处理顺序覆盖。
- 高度查询使用最终三角形的重心插值，禁止显示读离散地形、查询却返回理想曲面的双重标准。

目标道路面用于设计，离散后的地形面用于最终高度查询与规划验收。道路内部采用明确面片归属，不把多个路段和平台高度做距离加权混合。

### 3.5 窄边缘过渡

为让局部修改回到原地形，规划在道路支撑区外安排固定宽度过渡带，建议起步值 2 m。它不承担工程边坡、挡墙或挖填平衡功能。

- 固定道路支撑点的目标高差，过渡带外缘高差固定为零；禁改点同样固定为零。
- 过渡带其余格点以零高差初始化，执行固定 16 轮 Jacobi 邻域平均，双缓冲、固定顺序语义；不迭代到收敛，不回写道路内部。
- 所有道路共同在同一张局部格点表中处理，重叠过渡带不重复修改。
- 该方法只提供有限宽度的高度过渡，不承诺坡率或最小土方量；不足的平顺性由第一阶段的既定检查报告。
- 处理范围扩展到完整原生单元，且外边界增量为零。细网格边界按原生三角形插值落在旧地形边上，法线边界沿用原地形；首版不进行额外边界减面。
- 区域入口在地图外缘的高程需与原地形相容；不通过强行衰减道路内部高度实现地图边界拼接。

以上计算均在规划阶段形成确定的顶点修改计划。地形平整阶段负责应用该计划，而不是重新计算平滑或边界过渡。

### 3.6 第一阶段验证与失败行为

| 检查 | 对象与规则 |
| --- | --- |
| 输入和预算 | 参数合法、输入版本一致、坐标有限；格点、三角形和纹理预计规模不超预算 |
| 连通 | 所有必需锚点真实连通，输出道路不含孤立分量；广场内部连接显式存在 |
| 平面 | 完整路宽合法，转角无折叠、面片无非预期重叠和孔洞；三角形索引有效 |
| 目标纵断面 | 对分段多项式求导，检查坡度极值及连续性；不只比较两个远端点 |
| 离散路面 | 按最终地形三角形检查道路覆盖区域坡度、路口平台、横向高差及对设计面的偏差 |
| 平顺 | 沿最终地形面检查固定距离窗口的坡度变化；不要求分片线性网格有处处连续的数学曲率 |
| 接缝 | 共享边界坐标和高度一致；整平区域外边界回到原地形 |
| 禁改区 | 道路及支撑范围不能侵占禁改区；禁改点与修改区外的增量为零 |

面片归属、覆盖和拓扑采用几何检查；曲面误差及横向检查采用明确密度的采样，并记录密度，不宣称采样等于连续域证明。规划报告直接描述最终离散面，不能仅凭中间纵断面合格发布。

必需道路或最终整体表面不合格时不发布有效计划。可选次路只能在平面候选阶段被舍弃并记录原因，不能在最终阶段静默删除已承担必需连接的路段。取消保留上一份结果，标记其版本；失败草稿仅用于诊断。

## 4. 第二阶段：道路占地地形平整

输入 `RoadPlan` 与它绑定的原始地形，输出 `RoadTerrain`。

固定处理步骤：

1. 按计划的单元列表读取原始地形，应用已计算的目标顶点高度。
2. 构建计划指定的索引网格和普通法线，替换对应原生地形三角形；原始地图数组保持只读。
3. 按原生单元分组生成局部地形块，未受影响部分复用原网格。
4. 发布只读高度查询与地形网格，默认显示普通地形材质。

不再调用旧 `BedHeightAt` 将路基压低 3 cm，不生成道路裙边，不做近远两套地形或额外俯瞰副本。路面就是地形表面。

本阶段不重新采样设计曲线、不跑质量检查、不进行自动补救。资源创建异常正常报告失败，不能发布一半地形。任务完成时原子替换旧显示资源。

## 5. 第三阶段：道路生成

输入同一修订的 `RoadPlan` 与 `RoadTerrain`，输出 `RoadAppearance`。

### 覆盖纹理

- 从规划道路和广场占地光栅化单通道覆盖率，0 表示普通地面，1 表示道路。
- 路口和道路按占地并集绘制，不累加覆盖值；沿道路边界做像素级抗锯齿，不添加随机边缘侵蚀。
- 地形块按 16 × 16 个原生单元分组，约 83 m 只是当前地图下的示例。
- 每块建议 256 × 256 有效像素，当前地图约 0.33 m/像素；块边留采样边框并使用相同世界坐标，避免相邻块取样不一致。
- 只为有道路覆盖的块生成纹理。纹理、原点、尺寸随结果保存，不使用全地图超大掩膜。
- 首版使用线性过滤且不启用掩膜 mipmap，简化跨块边界处理；远景抗闪烁优化不进入首版。

### 材质显示

沿用地形着色器，按世界坐标采样所属块的覆盖纹理，将基础地形颜色和粗糙度混入统一道路材质。首版一种简单道路材质即可；主次等级由路宽表达，土路/石路分类作为后续表现扩展。

不生成独立道路顶点、三角形、MeshInstance、碰撞体或导航数据；使用已有地形块。共享 shader，按纹理绑定配置必要的块材质。掩膜不修改高度，也不决定土地归属。

本阶段只光栅化和绑定资源，暂不新增截图验收、碰撞检查或道路几何检查。

## 6. 数据契约与唯一高度来源

以下名称是拟定接口，不表示已经存在。

| 结果 | 主要内容 | 消费者 |
| --- | --- | --- |
| `RoadPlan` | 输入指纹/修订、参数、稳定路网 ID、锚点、权威占地与面片、目标纵断面、细分配置、目标格点高度与单元拓扑、覆盖纹理布局、规划报告 | 地形平整、道路生成、现有地块占地消费接口 |
| `RoadTerrain` | `RoadPlan` 修订、原始地形引用、局部顶点与索引、受影响块、只读高度查询 | 地形显示及现有高度消费者 |
| `RoadAppearance` | `RoadPlan`/`RoadTerrain` 修订、覆盖纹理、块材质绑定、显示配置 | 地形道路显示 |

规划格点高度可在第二阶段不可变地共享，不再额外保留一份全图浮点高度副本。查询始终在实际显示的三角形上插值；区外委托原始地形。

颜色、粗糙度、道路显示开关只影响第三阶段；路宽、路线、高度参数、细分精度、过渡宽度影响第一阶段并使后二阶段过期。

## 7. 节点、界面和下游关系

界面提供三个连续步骤：03 道路规划、03B 地形平整、03C 道路生成；各自可以独立运行和取消，也提供一次顺序执行三步的入口。

- 规划：少量路网/高度参数，预览中心线、占地、目标表面、预计挖填差和失败位置。
- 地形平整：显示原地形/修整地形切换、受影响面积、顶点和三角形数量；不新增一组高度参数。
- 道路生成：道路颜色/粗糙度、显示开关与生成状态；不包含几何精度参数。

| 变化 | 道路规划 | 地形平整 | 道路生成 |
| --- | --- | --- | --- |
| 地图、环境、聚落或道路形状/精度参数 | 过期 | 过期 | 过期 |
| 同一计划重新应用地形 | 复用 | 重建 | 重新绑定新结果 |
| 材质颜色/粗糙度 | 复用 | 复用 | 仅更新材质 |
| 隐藏道路材质、切换相机 | 复用 | 复用 | 不重新光栅化 |

地块仍从规划的权威道路占地获取临街和扣除信息；已有高度消费者可以通过 `ITerrainSurface` 读取修整地形。只进行必要接口适配，不借此调整建筑入口算法或恢复旧建筑验收范围。

第三阶段是独立的显示生成阶段，不成为地块有效性的前置条件。界面可以按三步展示，数据依赖不强迫改一次道路颜色就重算地块和建筑。

## 8. 参数、精度与效率

以下为**首版建议值**，用于形成可实施的起点，不是既有实测结论，也不是沿用旧工程级指标。

| 参数 | 建议值或规则 |
| --- | --- |
| 主次路宽、街道间距、最大纵坡 | 沿用当前道路参数；最大纵坡当前默认 10° |
| 纵断面采样步长 | 2 m，端点和必要转角额外补点 |
| 地形趋势平滑长度 | 20 m |
| 平台接近段 | 每端至多 10 m；短路段采用整体 Hermite 连接 |
| 离散路面横截面/目标面偏差 | 建议不超过 5 cm，平台接缝直接共享高度 |
| 长程坡度变化 | 建议 10 m 窗口内不超过 10 个百分点；短路段覆盖其完整长度，不按比例收紧为近零阈值 |
| 局部细分 | 默认 8，每个路宽至少约四个间隔；全计划统一选定，建议上限 16 |
| 边缘过渡宽度 | 2 m，另计道路边界采样支撑区和原生单元对齐余量 |
| 过渡计算 | 固定 16 轮 Jacobi，不运行收敛求解 |
| 材质覆盖精度 | 每组 16 × 16 原生单元对应 256 × 256 覆盖纹理 |

5 cm 是对离散地形表达的容差，不允许用它制造平台之间的实际台阶；10 m 窗口指标也不替代最大纵坡与突变检查。旧的 5 mm、2%/10 m、1.5 m 挖深/1 m 填高不自动继承。

效率约束：

- 路线搜索复用现有有限预算；每路段只生成一次高度候选，不做失败后的自动多轮优化。
- 地形面查询、掩膜光栅化均使用面片包围盒和空间分桶，不让每个格点扫描全部道路。
- 地形处理规模与受影响单元数成正比；固定轮数过渡为 O(格点数)，独立块可批量计算。
- 只保留一套修整地形几何，不叠加旧独立路面，也不创建全城高精度网格。
- 第一阶段在分配大数组前计算预计格点、三角形、掩膜字节数。建议初始上限为 100 万唯一细格点、200 万修整三角形、1600 万掩膜像素；超限报告预算不足，不偷偷降精度。
- 上述是资源规模上限，不是速度保证。设计阶段不承诺毫秒级耗时；后续实施记录三阶段耗时和峰值内存作为统计，不新增后二阶段质量验收任务。

固定网格不能精确表达任意细小弯道、窄间隙和理想截面。本方案接受有界离散误差；若未来要求毫米级精确表面，应重新评估边界约束网格或独立道路几何，不在首版中继续叠加求解器。

## 9. 现有实现的迁移边界

| 现有部分 | 处理方向 |
| --- | --- |
| `RoadGenerator`、`RoadNetwork`、占地及临街来源 | 保留有效逻辑与 ID 契约，作为规划基础 |
| `RoadGeometryPlanner` | 保留并集/分区/合法性能力；转角路径按简单离散表面统一，不维护多套高度投影 |
| `JointVerticalSolver`、旧曲率放宽、平台高度混合 | 新流程不调用；不为兼容旧验收继续修补 |
| `RoadGrading` / `GradedTerrain` | 拆分为规划目标数据与应用结果；保留合适的只读接口，不直接复用旧求解和路基压低逻辑 |
| `MapRenderer.Graded.cs` | 复用原生面替换、分组显示和资源释放；改为使用规划网格，移除新模式下的运行时减面、压低、重复细节网格 |
| `terrain.gdshader` | 接入单通道道路覆盖，普通地形和道路共用表面 |
| `RoadSceneBuilder`、`RoadLodRoot` 独立道路生成 | 新模式旁路，避免旧路面再次覆盖地形 |
| 碰撞、导航、挡墙与旧道路装配调用 | 新模式不调用，不为本次范围重写这些系统 |
| 节点状态和旧测试入口 | 必要适配；旧工程级测试与新规划验收分别标明范围，不使用旧通过报告宣称新方案完成 |

现有普通城市地面/道路预览若重复绘制道路，需在新模式下禁用对应重复面，这是接入所需的显示调整，不涉及新增建筑衔接设计。旧产物和历史报告保留，后续实现不先做大范围删除或全项目重构。

## 10. 实施顺序与完成边界

1. **完成规划数据与纯数据生成。** 复用路网，加入简单纵断面、平台、统一地形网格计划和第一阶段验证；报告最终离散面结果。覆盖直路、坡地、转弯、T/十字路口、广场、短路段、窄间隙和禁改区域等典型情况。
2. **接入地形应用。** 消费计划生成局部地形，取消新模式的路基压低与运行时二次几何处理；适配高度查询和失效链。不增加本阶段独立验证套件。
3. **接入材质道路。** 生成块覆盖纹理、绑定地形材质、关闭重复道路面，完成三阶段操作入口。不增加生成后验证或自动修复流程。
4. **整理交付记录。** 记录规划检查结果、三个阶段运行状态/规模/耗时及已知范围；明确第二、第三阶段未做独立质量验证，不把“资源生成成功”写成全面视觉或通行验收。

每项以对应功能接通为边界，不穿插挡墙、建筑、导航、正式美术或长期性能专项。本文仅完成设计；实现、运行结果和交付状态必须在后续实施时另行记录。
