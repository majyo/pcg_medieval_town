# 城镇区域布局重做：城内、城外聚落与乡野

更新日期：2026-11-03。状态：新的陆路区域预设已实施，见 [实现与使用](REGIONAL_TOWN_IMPLEMENTATION.md)。下文保留总体方案与条件性扩展；跨河桥头方案尚未实现。本方案替代上一版以城内为主要建设范围的总体假设。

## 1. 撤销的假设

上一版的核心问题不是墙线不够圆滑，而是将可用土地、城镇发展范围、城内范围混成一个集合：从可用土地边界内缩得到城墙，再将街巷候选限制到城内，城外仅保留短接入路和未分配土地。即使数据中存在“城外”标记，也没有真正生成城外城镇。

本次明确撤销：

- 从全部聚落土地边界内缩得到默认城墙。
- 城墙围合范围等于城镇主要建设范围。
- 所有重要设施放进城内，城外作为剩余或空白。
- 只有城内需要生成街道和宅地。
- 用缩小墙圈或增加几处墙外小房子的方式修补上一版。

新的总体对象是一个由交通、聚落片区、设施和生产景观组成的城镇区域。城墙只保护其中选定的核心区。

## 2. 历史依据及使用边界

先以**英格兰河流交通背景下、具有明显城外聚落的商贸城镇**作为首个预设，目标时代取约 1350–1450 年。以其他年代的材料解释结构延续时单独注明，不声称这些城市共享同一张标准平面。

| 证据 | 资料明确支持什么 | 用于本方案的判断 |
| --- | --- | --- |
| [Charlotte Berry，晚期中世纪伦敦研究导论](https://read.uolpress.co.uk/read/df3edff4-f74b-4458-a2ea-00af1341538e/section/efeaaec7-263e-47f7-8306-35a45faf194b) | 城外街区是城市生活的重要部分，包含食物生产、宗教设施等活动，居民也非单一贫困群体 | 城外应有正式聚落与经济功能，不能只作为空地或单一工业/贫民区。研究覆盖 1430–1540 年，借用其结构分析，不将十六世纪地图直接当作十五世纪原貌，也不照搬伦敦的规模 |
| [Richard Newman，Barnwell 考古研究](https://www.tandfonline.com/doi/full/10.1080/00665983.2020.1754622) | 十三世纪形成的修道院门外聚落，与剑桥核心之间隔着约一公里田地；至十三世纪末约容纳全镇六分之一人口，十五世纪开始衰落 | 城镇可由相隔空地的聚落片区组成，机构可以组织独立郊区。这里借用分离式片区关系，不把某个早期人口比例套用为十五世纪或所有城镇的比例 |
| [York 市议会：Outer Walmgate](https://www.york.gov.uk/downloads/file/1073/area-16-outer-walmgate) | 该区在十四世纪中叶之后才被相应石城墙围合，之前已有其他防御形式；现代面貌又经过显著改建 | 墙线是特定防御阶段的边界，不是城镇土地或街区的天然终点。不能据现代建筑外观直接复原中世纪布局 |

这些材料支持“城镇超出城墙、片区可以断续分布、边界与用途不能简单二分”。它们不提供可直接照搬的统一城外面积百分比。

本预设按用户意图，要求城外有显著规模的建设和生活空间。首个构图样例让城外宅地及设施用地与城内达到可比较的规模；这是项目构图目标，不是历史统计结论。森林、河流和未开发空白不计作城外城镇建设量。

## 3. 五种独立的空间对象

| 对象 | 含义 | 禁止的混用 |
| --- | --- | --- |
| 研究范围 | 地图取样、生成和相机观察的范围 | 不能把地图边界或一个圆当城镇边界 |
| 防御核心区 | 选择保护的中心街区、市场与机构范围 | 不能扩大到吸收所有郊区，也不由全部可用土地的外轮廓推导 |
| 城镇聚落片区 | 城内街区、城门外街带、桥头或河岸片区、机构周围聚落 | 不要求它们的土地多边形接触，只要求具有明确交通联系 |
| 独立设施与院区 | 宗教、仓储、集市、生产或领主设施及其占地 | 不默认全部位于城内，也不强制缩成普通住宅地块 |
| 城郊生产景观 | 园圃、果园、田地、草地和零散农庄 | 要表达用途和通路，不能统一归入“生成失败剩余空地” |

本次将“是否在墙内”“片区用途”“土地建设密度”分成三个属性。城内可以保留院区和空地，城外也可以有局部密集街段。

## 4. 首个样例的空间组织

采用河流与区域交通相联系的构图，包含以下主动规划的部分。各部分的位置由环境、通路和占地需求共同决定，不按等距同心圆铺设。

### A. 城内核心

占整个城镇建设的一部分，包含市场或主要市街、若干街区及城内公共设施。防御核心尺度单独控制，墙线沿选定防御区的可行边界布置，考虑地形、重要通路、城门落点和周长成本。

围墙可以完整围合核心，但不会包住全部城镇。河岸等是否成为防御边界需在具体预设中明确；首版可采用陆上闭合墙圈，不以“没有画墙的河边”自动当作完整防线。

### B. 城门外街带

至少两条具有明显长度和宅地数量的门外街带，沿不同方向的对外道路展开。临近城门可以紧密，向外变为断续临街建设、较深园地和支路片区；不是沿墙均匀绕一圈住宅。

同一城门可以承接多条区域道路，区域通路也可以绕过核心连接两个郊区。地图边缘入口与城门取消一一对应关系。

### C. 河岸或桥头片区

由已知跨河点、装卸位置或水力设施组织，配置相关仓储、工作场地与住宅。其道路优先接入区域通路，并与城门或城内市场有联系，不强制所有路线先经过核心点。

跨河点必须是显式输入或经过验证的规划连接，保存两岸端点、用途与通行要求。没有跨河能力时，不能把水面当可步行道路；也不能先删除整个对岸土地来规避问题。可先使用一个明确的既有桥位预设，正式桥梁模型另行制作。

### D. 城外机构及其附近聚落

设置一个有独立占地需求的宗教或公共机构，并让一组宅地围绕其入口或相邻街道组织。它可以贴近城镇，也可以与主城区之间隔着园地或田地；不把 Barnwell 的距离和人口比例机械复制到每张地图。

### E. 园地、田地与分散设施

在聚落片区之间和外缘保留有用途的开放土地，形成城乡交错的边缘。田地和院区应有通路，洪泛地、水域、保留林地等仍按环境限制处理。大面积空白必须能够解释为某种景观或未开发地，而不是街区切分失败的默认副产物。

首版必需部分为 A、两条 B 和一个城外设施聚落 D；C 根据是否存在已知河流连接/设施条件启用。E 为整体构图提供连续的土地背景。这样可以先做通用内陆样例，再增加有明确桥位的河流样例。

## 5. 一次性生成顺序

保持一次性节点工作流；以下均为本次计算内的固定阶段，不引入历史发展模拟。

1. **环境与区域通路**：读取研究范围，绑定外部目的地方向、既有通路和已知跨河点。生成少量粗略交通走廊与重要交汇点。
2. **核心与防御范围**：选择核心地点，按核心用地规模定义防御区。城门由穿越防御边界的通路需求确定；在有限候选中协调门位与墙线，并检查空间可行性。
3. **同时分配城内和城外片区**：给核心、门外街带、外部机构聚落等分别分配面积和密度目标。城外目标不依赖城内生成后的剩余空间。
4. **设施与生产景观**：先预留大院区、集市或工作场地，安排片区之间的园地、农田和通行联系。
5. **详细街道**：分别细化城内与各城外片区的街道；区域通路始终贯通。只有穿越墙线的道路必须经过城门，城外道路之间可以直接连通。
6. **按片区生成宅地**：城内、门外街带、机构周边、河岸工作区采用不同的临街、进深、占地和院落规则。
7. **审查总体构图**：先检查全部区域的分布、交通、占地和实际城外建设量，再生成建筑体量。

区域交通走廊是布局阶段的约束与意图，不冒充已通过全宽和纵坡检查的最终道路。详细道路无法落实时明确报告，采用有限的候选回退；失败后不发布混合版本，也不重新进入无限反馈循环。

## 6. 新的数据契约

拟将现有聚落输出改为区域性的 `TownLayout`（名称可在实现时统一），而不是继续增加一个 `Included` 掩码的隐含语义。

| 分组 | 内容 | 下游责任 |
| --- | --- | --- |
| `StudyArea` | 环境来源、版本、研究范围 | 数据覆盖和查询 |
| `RegionalLinks` | 外部目的地、粗交通走廊、显式跨河连接、必要可达关系 | 道路细化与连接验证 |
| `FortifiedCore` | 防御区、墙线、占地/缓冲、城门及关联通路 | 穿墙约束；不限制整个城外道路网络 |
| `Districts` | 多个片区的边界、角色、密度与宅地模式；可彼此分离 | 分区街道、宅地与建筑 |
| `Precincts` | 设施占地、入口和所属片区，可位于城内或城外 | 避让和专门布置 |
| `LandscapeParcels` | 园圃、果园、农田、草地、保留地及通路 | 环境与农业表现 |
| `DevelopmentSummary` | 城内/城外实际宅地与设施面积、片区数量、交通连通和缺口 | 总体布局验收 |

环境的限制数据可以继续用网格表达；区域、片区和防御边界使用显式几何。不能先用“核心所在单一连通土地”裁掉整个区域，跨水体或开放地分隔的片区需要保留并检查连接条件。

## 7. 道路与宅地规则的重置

- 路网在整个城镇区域内生成，城门只约束穿墙动作。撤销当前“次路候选必须在城墙内”的过滤。
- 每个城外片区必须具有可说明的核心或道路依托，并有接入区域路网的路径；不能为了填面积随机撒小地块。
- 城内街区可以更紧凑，街带宅地可以更深且断续，机构和河岸工作区使用较大的专门用地。
- 前街后院保留为一种宅地模式，而不是所有位置必须使用的统一条带模板。
- 城内外都有混合居住和经济活动，按具体环境与设施分配组合，避免“城内商业富人、城外工业穷人”的机械分区。
- 墙脚空带宽度和使用方式作为单独可调约束，首版不宣称历史城市都存在同样宽的连续净空环带。

## 8. 参数与预览

常用参数改为：区域研究范围、城内核心规模、门外街带数量与发展强度、城外机构片区数量、片区密度、道路依托和种子。墙体厚度、街巷尺寸和宅地细分属于后续层级，不能决定整个城镇的外轮廓。

默认预览必须展示完整城镇区域，不再仅放大墙内几百米。提供：

1. 总体分布：核心、城外聚落、设施、生产景观和明显空隙。
2. 城内/城外建设：只统计真实规划宅地与设施，不计水域、树林和闲置背景。
3. 交通联系：区域道路、城门、跨河点及各片区接入关系。
4. 防御范围：单独显示墙线及保护范围，同时保持城外聚落可见。

先用区域色块、少量示意宅地和交通线审核，不以生成了多少细小多边形替代总体布局评审。

## 9. 进入实现前的验收条件

- 城外至少有两条可辨识的建设街带和一处独立设施聚落；其实际宅地与设施规模须达到本预设的构图目标，不靠外围空地凑数。
- 可直接区分研究范围、防御核心和整个城镇的分布范围。
- 城外区域存在明确用途、道路依托和空间差异，不是均匀环带或稀疏随机点。
- 片区之间允许有田园间隔；所有需要通达的片区都有真实或显式规划的连接条件。
- 城内不被要求填满，城外也不被要求一律低密度；具体密度有片区依据。
- 同一份俯视方案上能解释重要设施为何在那里，以及道路为什么连接这些地方。

后续先完成一张清楚的总体布局样例并核对上述条件，再进入生成器重写。环境采样、几何运算和版本管理可以复用，上一版宏观布局与城外生成逻辑不作为新方案的基础。
