# 场景布置节点

更新日期：2026-11-04。状态：首版已实现，接入 06 场景布置面板。

## 流程与职责

```text
环境采样 → 聚落布局 → 道路规划与定型 → 街区地块 → 建筑体量 → 场景布置
```

节点从有效的只读输入一次生成完整 `ScenePlacementSet`，复用已有道路、建筑和地块，补充院落地面与少量公共、私有附属设施。规划结果由独立装配器生成 Godot 场景根节点 `GeneratedTown`。重新生成替换这个根节点，场景内不会累积旧对象。

现阶段提供内置土木与内置灰模两种程序模型方案。建筑主屋、院区、屋顶、基础、入口台阶与共墙来自原有 `BuildingSet` 和 `BuildingMeshBuilder`。棚屋、摊棚、储物堆、井、长凳和围栏使用有明确尺寸的内置模型。资源键形如 `builtin/shed-v1`，库版本为 1；任意外部美术资源导入、自动尺寸适配、独立场景文件导出仍需后续资源适配器。

## 使用与参数

依次生成环境、布局、道路、地块和建筑，选择 **06 场景布置 → 独立生成场景**。显示选项只改变预览；生成参数变化会标记场景过期。场景局部重跑复用上游，不重新选线或划分地块。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 资源方案 | 内置土木 | 改变基础材质配色；内置灰模用于结构检查 |
| 公共与临街密度 | 0.4 | 公共院场、市场和有效商住/作坊临街位置的布置强度 |
| 院落设施密度 | 0.6 | 有主屋的后院、作坊院地的附属设施密度 |
| 带开口的围栏 | 开 | 在选定后院沿宅地边界放置有限围栏段，通院和物件入口保留缺口 |
| 自然植被避让 | 开 | 用显示掩膜过滤城镇、生产用地及必要通道内的自然树木 |
| 附属物总预算 | 1200 | 包括每段围栏在内的对象总数，范围 0–4000 |
| 布置种子 | 73129 | 控制候选位置、设施选择和参与围栏布置的后院 |

公共对象优先于私有附属物，围栏最后布置。每个物件最多尝试 18 个候选位置；每个入选后院最多生成 8 段围栏。预算耗尽和可选对象无合法位置会形成诊断，不会填占保护区域。

## 输入衔接

| 来源 | 用途 |
| --- | --- |
| `RoadNetwork.Geometry.Area / Surfaces` | 原样继承定型道路的平面占地和面片来源 |
| `RoadNetwork.Landscape` | 使用道路裁切后的农田、果园、草地与耕作线 |
| `LandParcel.Shape / Yard / Use` | 私有土地归属、后院范围、作坊及商住布置规则 |
| `BuildingMass` | 保持建筑尺寸、位置、门口、基础、屋顶及院区体块 |
| `BuildingAccess` | 保护已有入户、侧道、共享通院与院区入口，并提供附属物通路的接入点 |
| `SharedWalls` | 复用原有共墙去重渲染，避免重新实例化重复墙面 |
| 聚落广场、城门与城墙预留 | 公共布置区域和明确的通行、占地限制 |
| `CityEnvironmentData` | 整个物件及接入通路覆盖的采样单元合法性、落地高差 |

运行时检查环境、道路、地块、建筑的对象引用及对应修订号，拒绝混合不同生成链的结果。缺少主屋的地块保留原状，后院设施只关联已成功生成主屋的地块。

## 几何和通行规则

1. 将道路、屋檐、城墙预留、城门和既有通道登记为保护空间。既有通道外增加 0.2 米的附属物避让余量。
2. 道路面片保持定型结果；其他地面按通院、广场、院场、后院、田园顺序扣除已占地，形成内部不重叠的地面区域。建筑实际占地不重复铺地。
3. 每个候选物件检查完整占地包含关系、与既有物体及通道的冲突、所覆盖环境单元，以及最多 0.4 米的局部地面高差。模型底部用必要的简单支撑处理高差。
4. 非围栏物件从已知的院落或公共入口接入，检查一条 1 米宽的直接通路；通路必须位于有权使用的区域内，避开建筑、墙体、受限地面及已有物件。无法直接接入时换候选位置，尝试耗尽则跳过。
5. 已接受的通路进入空间索引，后续物件和围栏不得堵塞。物体之间保留 0.25 米间距。
6. 围栏向自有宅地内退让，只放在后院可用部分。通道相交的围栏段跳过，形成开口；同侧重复或相邻过近的围栏通过空间避让剔除。首版不保证每个后院完整围合。

空间查询使用局部索引，避免每次候选或地面裁切都遍历整座城镇。所有处理有候选与对象预算；没有运行中的城镇生长状态。

## 输出

`ScenePlacementSet` 保存建筑输入、建筑修订号、参数快照和只读集合：

| 字段 | 内容 |
| --- | --- |
| `GroundPatches` | 地面类型、来源、道路引用及完整多边形 |
| `BuildingPlacements` | 原建筑体量引用及内置生成规则 |
| `Props` | 稳定对象 ID、类型、资源键、所属区域、实际占地、尺寸、高程、支撑与接入通路 |
| `Zones` | 布置域、土地归属、方向和已有入口锚点 |
| `ProtectedSpaces / ProtectedArea` | 来源可追溯的保护区域及合并约束 |
| `VegetationMask` | 交给环境宿主的植被避让形状 |
| `Issues / CandidateAttempts` | 跳过原因、位置、尝试次数和预算诊断 |

领域数据不持有场景树节点。`SceneMeshCache` 将结果转成可复用网格数据，`SceneAssembler` 创建合并的地面、建筑、附属物与诊断显示组。网格保留对象来源，合并绘制后仍可点击追溯。

## 植被与地面

当前正式链的院地按修整地形裁切和细分，控制贴地插值误差；道路与广场由独立的正式路面覆盖。规划测试仍保留原环境三角形适配器。显示使用小幅高度偏移，地形修整和土方归 03B，06 不修改输入地形。

`MapRenderer` 根据掩膜重建森林显示缓冲区，以树冠范围而不只是树干点检查避让。当前内置树采用 `8 × Scale` 米的保守平面树冠范围。隐藏场景或关闭避让后恢复自然森林；地图的原始树木列表、位置、高度、种子及地形数据保持只读。田园仍使用既有轮廓和耕作线，尚未生成农作物资产。

## 四层预览

| 图层 | 内容 |
| --- | --- |
| 场景总览 | 地面、建筑、附属物、城墙平面占位及避让后的自然环境 |
| 分类与来源 | 建筑用途和附属物类型分色；点击显示对象 ID、地块/院区、资源键及尺寸 |
| 通行与占地 | 青色保护通道、浅蓝附属物入口、橙色附属物占地、建筑屋檐边界 |
| 问题与落地 | 跳过位置、植被避让边界和按落地高差分色的物体轮廓 |

面板提供全城、市场和院落近景。显示切换保持输出修订号；旧结果有状态提示，不作为有效输入。生成期间锁定上游参数，取消与失败不发布部分场景。

## 验证和当前范围

```powershell
.\tools\project.ps1 test-placement
.\tools\project.ps1 test-placement-ui
.\tools\project.ps1 capture-placement
```

`test` 包含场景布置的数据验证。三组地图种子检查土地归属、通道保护、落地、物件碰撞、道路边界继承及地面面积账目。默认地图还验证实际模型投影、高度、法线、三角形绕序和地面贴合，以及复现、种子差异、零密度、对象预算、资源方案、输入版本、定型后取消和运行中失效。

真实 Godot 界面验证独立生成按钮的视口输入、四层显示、物件点击、局部重跑、取消、可选参数、上游失效、道路到场景的完整链，以及植被过滤和恢复。该验证使用引擎视口输入，不等同于实体鼠标键盘测试。

报告：`artifacts/placement_validation.json`。截图：`artifacts/captures/placement_*.png`，包含全城、市场、院落、来源、通行和问题六张。

当前使用程序模型和基础配色，展示层有基础建筑细节；道路横坡、修整地形、碰撞、道路与入口导航已由 03B 和最终装配接入。实际城防工程、外部美术资源适配与室内仍不在当前交付范围。

本次三组种子验证通过 19,946 项检查，完整地图至场景数据链与既有节点界面回归通过，构建零警告、零错误。默认场景装配 654 栋建筑、1,447 片地面和 1,200 个附属对象：797 段围栏、348 组储物、49 座棚屋、4 座摊棚、1 口井和 1 张长凳。自然森林显示过滤 537 棵树，隐藏场景后恢复。79 条诊断包含候选无合法位置和对象预算用尽。


## 2026-11-06 道路施工接入

06 通过建筑/地块引用同一份 `RoadGrading` 和 `GradedTerrain`，附属物、院地及台阶落地使用修整高程。正式装配有效时，道路/广场旧地面片仅保留占地与来源数据，不重复绘制。植被掩膜只保存查询轮廓，避免对大型布尔并集做无用途的三角化。

正式铺装、道路/地形/建筑碰撞、道路与入口导航、三维运行道路图及独立场景导出由最终装配负责，配置变化不使 01–06 过期。当前范围及验证见 [道路施工](ROAD_CONSTRUCTION_NODE.md)。
