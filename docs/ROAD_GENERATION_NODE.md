## 1. 职责与首版范围

**把聚落的范围、核心和出入口，转换成具有真实连接关系和道路宽度的路网，供街区地块提取和场景布置使用。**

首版完成：必需主路连接、有限的次路布局、地形避让、交叉口整理、道路占地与连通检查。生成结束后一次发布完整结果，修改道路参数只重算道路及其下游。

首版采用两级道路、单层地面网络。主路负责入口与核心通达；次路按照间距与方向形成可供划分街区的网格，并通过小幅扰动适应不规则形态。道路可以形成环路，也可保留合格的支路。桥梁、隧道、立交、交通流模拟、路面施工和建筑放置留给后续明确扩展。

## 2. 如何使用现有聚落输出

声明两个输入端口：`environment: CityEnvironmentData`、`settlement: SettlementLayout`。当前聚落结果已持有 `Environment` 引用，独立调用时可以从该引用取环境；接入通用图后两条依赖必须指向同一个采样结果，不能混用新环境和旧布局。

| 已实现的字段 | 道路节点如何使用 |
| --- | --- |
| `Cells` / `Contains` | 以 `Included` 单元的并集为允许道路占用的区域；孔洞、未知和未纳入片区保持排除 |
| `Boundary` | 用于检查路宽、定位终止边界；`Outer` 区分外缘和内部孔洞 |
| `Core` / `CoreId` | 必须可达的核心节点，保留对上游核心的引用 |
| `Entries` / `EntriesRequireConnection` | 每个发布的入口必须连接核心；保留 `Id`、`Position` 和 `Edge`，不能以其他候选替换失败入口 |
| `LayoutEntry.Edge.Outward` | 确定入口向城市内部接入的方向，避免道路沿边界切向擦过入口 |
| `Plaza` / `PlazaId` / `PlazaAllowsRoads` | 核心广场可通行，道路可接入或穿过；广场仍由聚落布局保留，普通建筑不得占用 |
| `LayoutCell.Reserved` | 当前表示公共广场预留，不可直接作为道路障碍；采用 `PlazaAllowsRoads` 明确处理 |
| `InputNodeId` / `InputRevision` | 验证聚落使用的环境采样版本；还需由宿主绑定聚落节点自己的实例 ID 与 `ResultRevision` |
| `Options` / `Warnings` | 规划意图和诊断背景；规划圆不是道路可越过实际区域的许可 |

`EntryCandidates` 只服务聚落选入口，`LayoutCell.Score` 只服务核心选址。道路节点不根据它们悄悄换入口或重选核心。道路自己的成本评分独立计算。

**输入的土地连通不等于道路可通。** 两片区域之间可能只有狭窄连接，入口附近也可能放不下道路。必需连接失败时报告具体入口和原因，由用户调整路宽或回到聚落节点改布局；节点不修改上游结果。

## 3. 参数面板

| 参数 | 首版起步值 | 用途 |
| --- | --- | --- |
| 主路宽度 | 8 米 | 主路总占地宽度 |
| 次路宽度 | 5 米 | 次路总占地宽度 |
| 街道间距 | 80 米 | 控制次路模板密度与街区尺度 |
| 主方向 | 自动 / 手动角度 | 自动取核心到最远入口的方向，同距按入口 ID；另一组次路与其垂直 |
| 不规则程度 | 默认 0.15，范围 0–0.25 | 模板顶点偏移量相对街道间距的比例 |
| 最大纵坡 | 暂定 10° | 路段沿行进方向的高差限制 |
| 最大地表坡度 | 暂定 12° | 道路占地所覆盖单元的最大采样坡度；与纵坡分别检查 |
| 有效种子 | 城镇种子与道路节点 ID 派生，可覆盖 | 固定模板偏移及同分候选顺序 |

这些是原型起步值，尚未经过城市形态或道路工程验证。主路宽度不得小于次路宽度；间距须大于最大路宽及必要的分隔距离，参数不合理时直接报错。

搜索展开量、次路候选总量、最大路段数量设置为有限内部预算，首版不堆满常用面板。预算耗尽与几何不可达必须分别报告。显示输入网格间距和结果精度说明。

## 4. 一次生成的执行步骤

### 4.1 固定输入与道路可用空间

检查两个输入及其版本一致，固定参数和种子。道路只能占用聚落纳入区域，广场作为可通行公共空间。对每种路宽分别计算可用的中心线位置和相邻连接；检查整段道路走廊覆盖的所有单元，而不只检查端点。

首版沿用环境网格作路径搜索，以单元中心作为主要候选位置，允许八方向连接；斜向移动也必须通过整段走廊检查，禁止从障碍角点之间穿过去。核心、入口作为精确的连续坐标锚点，使用通过同样检查的短连接接入搜索网格。

搜索使用路径长度、纵坡代价、转弯代价与可选植被代价的非负组合。复用已有主路可降低相对代价，但不产生负代价。未知环境不能被较低成本抵消；植被缺失则停用对应软评分，不将缺失当作零。

### 4.2 连接全部入口与核心

以核心为初始锚点，按入口 ID 的稳定顺序，为每个入口寻找通往已连通主路的合法路径。首次连接到核心，后续可接入已有主路并共享路段；接入点必须生成真实拓扑节点。以主路宽度搜索和验证，不先铺窄路再无条件加宽。

入口位置保持不变，第一段向内部接入，限制在与 `-Outward` 一致的方向范围内。入口位于区域边界，终点采用平端截面：道路在该入口边界截面结束，不能因圆形端帽延伸到区域外。入口开口的整个宽度仍须落在合法外缘上，侧边不得借此穿入孔洞或越界。首版不绘制延伸到未采样外部目的地的道路。

核心与广场也保持原位置。道路在广场内的图连接仍需显式记录，不能仅靠两条道路看起来都进入广场便宣布相通。

任一必需入口无路、路宽不足、坡度超限或预算耗尽，本次节点失败。失败诊断可以显示已求出的草稿与失败目标，但不能发布为有效 `RoadNetwork`。

### 4.3 一次布置有限次路候选

以核心为模板原点，在实际区域包围盒上按主方向、间距生成有限的二维网格。按稳定顶点键与种子为共享顶点生成一次偏移，再连接相邻顶点得到候选；相邻街道使用相同共享顶点，避免各自抖动导致接不上。

裁切并检查候选走廊。遇障碍时，只允许在有限的局部范围内绕行；无法通过的部分不接受。保留能接入主路的候选网络，删除与主路完全断开的分量。允许多条次路互相连接后整体接入主路，不以“候选被处理时是否已经接通”错误删除后续可连接的街区。

候选数量由范围和间距确定，所有候选最多规划一次，按固定预算完成。清理距已有道路过近的重复走廊和没有实用长度的碎段；真正提供临街面的合法支路可以保留。首版通过模板本身形成环路，不再引入覆盖率反馈或反复扩张机制。

### 4.4 整理交叉口、几何与占地

处理同层路径的相交、T 形连接、重合路段与近距离端点：

1. 几何相交处创建共用节点，并分割相关边；单纯线条交叉不算拓扑连通。
2. 合并完全重合的路段并保留较高等级；需要升级宽度时重新检查空间，不能覆盖不合法区域。
3. 仅在位置和高程都相容、且合并后的走廊合法时吸附近端点；固定核心和入口不移动。
4. 有限地简化折线、削去多余锯齿。每次简化都重新检查宽度、坡度与约束，失败则保留原折线。
5. 为中心线生成路段带、接角与交叉口占地，检查整片占地合法。

首版使用折线、直线段和有限的削角连接即可。自由样条平滑不作为交付前提，避免视觉上顺滑但路带侵入障碍。

### 4.5 完整检查并发布

从核心遍历最终拓扑，确认每个入口可达、所有输出道路属于该连通网络。检查 ID 引用、零长度、重复边、未分割的平面交叉和占地冲突。

输出闭合街区候选数量及剩余土地的道路覆盖情况，用于发现“只有几条连接线、没有可用街区”的结果。首版不承诺每次都有闭合街区：例如狭长区域只能产生支路时，可在主路合法的前提下成功并警告“未形成闭合街区”。街区与地块节点仍负责最终的面提取和有效地块检查。

最后复查输入版本与取消信号，成功时一次发布新修订号。次路部分候选跳过可附警告；必需主路失败或取消均不发布部分网络。

## 5. 路宽、坡度与精度

- 道路占地是整条走廊，包括转角和交叉口。区域外、孔洞、水域、未知与禁建限制不能靠中心线检查绕过。
- 纵坡按中心线分段地面高差与水平长度计算。沿途在采样三角形边界处分段，避免只看远端高差漏掉中间起伏；占地内的地表坡度独立检查。
- 当前 10 米网格允许生成 5–8 米宽的宏观道路表达，但只能验证采样数据表达出的限制，不能证明真实地形的窄水道和细小陡坎不存在。
- 将同一份粗采样插值到更密网格不会增加环境信息。需要更精细判断时，用户先重跑环境采样，再重跑聚落和道路，不能用新采样搭配旧布局。
- 节点不生成填挖方、不整平原地形，也不把沿地形折线自动视为已可供角色导航的道路。

## 6. 输出 `RoadNetwork`

一个输出端口 `roads`，以下按领域职责分组，实际代码使用只读属性与集合。

| 数据 | 最少内容 | 使用者 |
| --- | --- | --- |
| 输入版本与配置 | 两个输入的节点 ID、结果修订号、参数快照、有效种子、采样精度 | 执行器、复现与预览 |
| `Nodes` | 稳定 ID、平面位置、高度、核心/入口/交叉口/端点角色 | 连通检查、路口表现 |
| `Edges` | 稳定 ID、首尾节点 ID、有序中心线点列、等级、宽度、长度、最大纵坡 | 地块临街关系、道路显示 |
| `AnchorBindings` | 核心 ID 和每个入口 ID 对应的道路节点 ID | 检查全部必需目标是否真正接通 |
| `RoadFootprint` | 道路带、接角及交叉口的二维占地几何；约定其并集为道路占地 | 街区地块扣除、场景避让 |
| `Summary` | 主次路长度、交叉口/支路数量、必需连接完成情况、闭合街区候选数、警告 | 调参、结果检查 |
| 调试诊断 | 被拒候选及原因、预算截断、失败位置；与运行或结果修订号绑定 | 诊断图层，不作为下游几何输入 |

中心线按边的首尾顺序保存，相邻边共享真实节点。一个边内部的折点只负责几何形状，不必把每个折点都创建为交叉口。

占地几何可以由多个相互重叠的简单多边形表达，其语义是并集。消费者不可直接把各多边形面积相加；道路覆盖面积如采用栅格估算，需标为估算并去重。粗栅格覆盖层只作查询加速和预览，不能代替道路宽度几何去切精细地块。

地块节点使用建设区域，扣除道路占地并集与广场预留，形成剩余街区，再建立地块与道路边 ID 的临街引用。道路穿过广场时占地重叠按并集处理，不能重复扣除。道路节点输出领域数据，渲染网格由预览器生成，正式资源实例由场景布置生成。

## 7. 可视化与操作

默认复用现有三维地图与俯视相机，聚落布局以低透明度作背景。主路较宽、次路较窄，核心和 E1/E2 标记保持可见；所有路带均按参数宽度绘制。

| 图层 | 显示内容 | 重点回答 |
| --- | --- | --- |
| 路网总览（默认） | 贴地道路带、主次等级、核心广场、出入口 | 城市道路形态是否清晰，密度是否合适 |
| 连接关系 | 简化中心线、交叉口圆点、核心到入口的连通高亮、端点标记 | 路口是真连接还是仅线条交叉，必需入口是否可达 |
| 道路占地 | 完整路宽、接角和交叉口占地，聚落边界与障碍轮廓 | 是否侵入禁区，是否留有可用的街区空间 |
| 坡度与问题 | 路段纵坡分色、失败锚点、被拒候选、超预算标记 | 哪段路难以通过，调哪个参数有帮助 |

诊断使用形状、线型和文字配合颜色。未通过的候选用红色虚线，标明“失败诊断”，不以正式道路样式混入成功结果。正式结果和旧结果绑定各自修订号。

点击道路显示等级、长度、宽度、坡度和首尾节点；点击入口，高亮它到核心的一条实际图路径。悬停地面可显示是否处于道路占地内。道路上的常规折点默认隐藏，选中时才显示，减少画面杂乱。

右侧新增“03 道路生成”：输入状态、少量参数、独立生成/取消、图层、结果摘要和定位按钮。输入过期时提示先生成环境或聚落；不静默触发地图重建。改路宽、间距或种子只使道路及下游过期，切层、相机和选中对象不触发计算。

## 8. 实现顺序与验收

1. **主路与真实连接**：接入当前聚落输出，完成主路搜索、全宽检查、核心/入口绑定、独立运行和总览预览。
2. **次路与街区形态**：加入有限模板、扰动、局部绕行、交叉口整理和孤立片区清理，检查典型场景能形成街区。
3. **占地契约与完整诊断**：完成道路占地、分层显示、选中详情、失败与取消处理、版本失效和测试。

验收至少包含：默认地图全部入口接通；同输入和种子复现；窄通道放不下路宽时拒绝；斜向路径不穿障碍角；入口平端终止与全宽检查；孔洞避让；广场内真实连接；相交处拆分与重合去重；平滑后重新检查；只保留接入核心的次路；必需失败不发布、可选跳过带原因；预算截断不冒充确定不可达；取消不发布草稿；上游复用与失效；四个图层与输出几何一致。

首版追求可检查的主次路网和可交给地块节点的空间边界。全城交通仿真、自动桥梁和精确工程施工不构成当前节点的前提。

## 9. 实现与运行（2026-11-03）

- `scripts/pcg/roads/RoadNetwork.cs`：只读路网、锚点绑定、占地多边形并集、路径查询、节点状态和几何检查。
- `scripts/pcg/roads/RoadGenerator.cs`：有限八邻接搜索、道路空间缓存、主路复用成本、次路模板、有限折线简化、相交与重合拆分、孤立分量清理及拓扑整理。
- `scripts/pcg/preview/RoadPreview.cs`：四个图层、实际路径高亮与失败诊断。
- `scripts/Main.Roads.cs`：03 道路生成面板、独立运行取消、输入失效联动及地图点击。
- `scripts/pcg/roads/RoadValidation.cs` / `scripts/Main.RoadValidation.cs`：无界面几何和生命周期验证、真实渲染与视口输入检查。

依次运行环境采样、聚落布局和道路。节点不隐式重建上游；输入失效时说明需要先生成哪个阶段。主路统一以核心为搜索终点，已接受主路给予非负的相对成本优惠，最终共享路段合并。所有入口位置保持不变，末端平截，不生成城外延长线。次路模板顶点投影到可用搜索网格，搜索和局部简化后统一拆分真实交叉口。

道路宽度检查采用凸多边形与采样单元的相交判定，排除任意覆盖非纳入单元的路带；纵坡在网格线和三角形对角线处分段计算。占地输出为路带与八边形接角/路口片的并集，保留内部几何折点，合并没有分支的同级拓扑链。首版不导出路面美术资产、碰撞或导航。细小障碍的可靠性仍取决于上游采样精度。

四层分别是路网总览、连接关系、道路占地、坡度与问题。失败诊断和旧结果都有状态说明；修改显示设置不会生成新结果。点击入口高亮图中的实际路径，点击道路查看等级、路宽、长度、最大纵坡及端节点。当前为固定独立节点的参数面板，参数会话内有效，通用图执行器仍未实现。
