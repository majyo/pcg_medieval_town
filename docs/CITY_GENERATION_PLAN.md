# 城市一次性生成方案

更新日期：2026-11-04  
状态：环境采样、区域布局、道路、道路竖向与地形修整、街区地块、建筑体量与场景布置七个独立节点已有实现。节点执行、取消、结果复用与失效遵循 [PCG 框架](PCG_FRAMEWORK_DESIGN.md)。

## 目标与工作方式

**当前以 [城镇区域布局重做](REGIONAL_TOWN_LAYOUT_REDESIGN.md) 为新的总体设计。** 新的陆路区域预设已接入，使用与实现范围见 [区域布局实现](REGIONAL_TOWN_IMPLEMENTATION.md)。下文含旧阶段记录，以新方案的空间对象和当前实现说明为准。

形态方向已按用户反馈收敛到十三至十五世纪参考，详见 [城市形态修订](MEDIEVAL_URBAN_FORM.md)。城墙/城门、公共院区、不规则街巷与前街后院首版已接入。详细数据与当前范围以形态修订文末为准。以下保留节点边界。

**给定环境、布局参数和种子，通过固定的生成阶段直接得到一座可预览的城市。** 先用道路、地块色块和简模建筑验证形态，再替换表现资源。

```text
环境采样 → 聚落布局 → 道路（路网规划 → 几何定型）→ 街区与地块 → 建筑生成 → 场景布置
```

每个节点读取上游完整结果，一次计算、一次发布并结束。用户可以运行到任一节点检查结果，修改该节点参数后独立重跑，再更新下游。每次重跑从输入与种子开始；建设范围、道路间距、地块尺寸和建筑覆盖率直接控制最终形态。

## 各节点的最小实现

### 1. 环境采样

使用已有 `EnvironmentSampleNode`，读取外部地图并输出 `CityEnvironmentData`。范围、采样精度与静态限制保持现有契约；生成道路和建筑时显式检查其所需精度。

### 2. 聚落布局

详细契约与预览见 [聚落布局节点](SETTLEMENT_LAYOUT_NODE.md)。输入：环境采样结果。首版参数：规划中心与半径、自动或手动核心、出入口、核心广场尺寸、最小可用面积与种子。

首版使用一个主核心，在圆形规划范围内选择合法位置，保留核心所在的四邻接可用区域；人工核心直接检查。边界入口需具备附近的对外陆地延伸条件，核心预留一块可通行的公共广场。实际道路连通仍由道路节点验证。

输出 `SettlementLayout`：规划范围、只读区域掩码及含孔洞的派生边界、核心、对外入口和广场预留，附输入版本、面积与约束诊断。人工指定且必需的位置不合法时明确报错。任意多边形绘制、多核心和其他设施选址后续再扩展。

### 3. 道路生成

详细职责、输入映射、输出与预览见 [道路生成节点](ROAD_GENERATION_NODE.md)。首版先保证全部入口与核心通过主路连接，再用有限的次路模板形成街区；道路全宽和真实拓扑连接均需检查。

输入：环境采样与聚落布局。参数：道路等级与宽度、主方向、街道间距、角度与位置扰动、坡度上限和搜索预算。

一次生成按固定顺序完成：

1. 连接核心与必需的对外入口，形成主路骨架。
2. 在建设范围内按主方向和间距布置有限的次路候选，可用受控偏移形成不规则街区。
3. 结合坡度、水域、禁建区与设施预留调整路径，裁去范围外及不合法路段；必要的绕行使用有界路径搜索。
4. 处理交叉口和路段分割，合并重复节点，清理零长度、重复和孤立路段，验证必需入口连通。
5. 在发布前完成 [道路几何定型](ROAD_GEOMETRY.md)：约束内平顺内部折点、整理路口和宽度过渡，输出权威占地、不重叠面片与可追溯的临街边界。地块和后续道路场景资源共用此结果。

输出 `RoadNetwork`：有稳定 ID 的交叉口、路段中心线、等级、宽度、道路占地区域与连通诊断。候选数量由范围与间距确定，搜索预算限制计算成本。

首版道路避开水域；河流阻断必需连接时报告无法连接，并提示调整范围或入口。桥梁作为后续独立的受约束连接能力加入。可选次路受阻可跳过并记录；必需连接失败则该节点失败，不发布不合格网络。

### 4. 街区与地块

首版已实现，操作与实际输出见 [街区与地块节点](BLOCK_PARCEL_NODE.md)。当前按用途面积目标自动分配，人工用途区域绘制留待扩展。

输入：环境采样、聚落布局与道路网络。参数：用途比例或指定区域、目标地块宽深、最小面积和道路退界。

从道路占地与建设边界提取可用街区，扣除水域、禁建区及设施预留。按指定区域优先、核心距离和用途比例分配住宅、商业、生产等用途，再根据临街边细分地块。用途比例是布局偏好，实际面积随几何约束报告。

输出 `ParcelLayout`：街区与地块边界、用途、可建筑区域、临街道路引用和落地限制。检查多边形有效性、地块重叠、最小尺寸、退界与临街关系；剩余狭小区域记为空地，无法形成有效地块时给出诊断。

### 5. 建筑生成

下一步详细设计见 [建筑体量生成节点](BUILDING_MASSING_NODE.md)：先完成普通主屋、街段与通院关系、公共院区和简化屋顶的三维体量验收。首版已实现并接入 05 建筑体量面板；实际范围和验证见该文末。

输入：环境采样与地块。参数：用途对应的建筑规则、尺寸范围、覆盖率、层数与风格。

首版直接生成简模体量，按临街方向放置，在可建筑区域内检查占地和地面高差。每个地块只尝试有限组尺寸与朝向，放不下时跳过并记录原因。

输出 `BuildingSet`：建筑 ID、地块引用、体量或资源标识、位置、朝向及落地数据。检查建筑位于允许范围内、互不重叠且符合坡度和高差限制。结果附成功数量、未利用地块及原因。

### 6. 场景布置

首版已实现，实际接口、参数、布置规则和验证见 [场景布置节点](SCENE_PLACEMENT_NODE.md)。道路、建筑、院落地面与内置附属设施装配成单独场景根，支持植被显示避让和来源追溯。

输入：环境采样、聚落布局、道路、地块和建筑。参数：资源映射、装饰密度与间距。

生成道路表现、设施、建筑资源和少量装饰物的放置数据，避开通道、既有障碍和植被。输出 `ScenePlacementSet`，由展示或导出代码实例化。管线外地图保持只读。

城墙与城门的平面占位已在聚落布局中输出并约束道路、地块。正式墙体、道路美术几何及桥梁按后续需要实现。

## 运行与结果检查

- 一次运行固定输入、参数和种子，计算完成且检查通过后发布完整结果。
- 必需约束失败时返回错误；允许跳过的可选对象附原因与计数，便于判断结果是否可用。
- 取消或输入改变时丢弃当前临时输出。再次生成使用当前输入与种子从头计算。
- 道路搜索、几何优化和放置尝试均有有限预算。界面可显示计算进度，完成后查看正式结果。
- 修改道路间距只使道路及下游过期；修改建筑风格只使建筑及布置过期。上游环境与聚落布局可直接复用。

## 交付顺序与验收

| 阶段 | 可见结果 | 核心验收 |
| --- | --- | --- |
| 已有环境采样 | 环境事实与建设限制叠加图 | 只读、可复现、取消不发布部分结果、参数变化使结果过期 |
| 聚落布局 + 道路 | 建设边界、核心、入口和完整路网 | 合法选址、必需连通、正确交叉口、避让地形约束、固定种子复现 |
| 地块 + 简模建筑 | 可观察的城市体量 | 地块有效且临街、建筑占地与落地合法、跳过原因明确 |
| 资源布置 | 可查看和导出的场景放置结果 | 引用有效、通道可用、空间避让符合规则 |
| 通用节点编排 | 统一的局部重跑与结果预览 | 依赖正确、上游复用、下游失效、取消和失败不发布部分结果 |

首先完成固定流程的业务结果和独立调参入口，再接通用执行器及可编辑节点画布。首版质量以形态可用、生成可控、约束可查和快速重跑为准。
