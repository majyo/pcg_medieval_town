# PCG City Sandbox

基于 Godot 4.7.2 .NET（C#、.NET 8）的中世纪城镇程序化生成沙盒。在 2 × 2 km 的温带平原地图上，用一张由节点组成的生成图造出一座带城墙的小镇，节点分为六组：

**场地采样 → 场地评价 → 区域格局 → 城镇布局 → 路网 → 街区与地块 → 建筑**

每个节点只做一个决策（选城址、画城墙、修主街、切地块……），节点之间只通过命名的数据键交换数据，所以任何一个节点都可以单独替换。

结构、数据和规则见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 运行

用 Godot **.NET 版**打开 `project.godot`，或在项目根目录执行：

```powershell
.\tools\project.ps1 run       # 打开沙盒，启动后自动生成整座城镇
.\tools\project.ps1 test      # 组件依赖检查 + 无界面检查：三个固定种子 × 地形与城市不变量 + 可复现性
.\tools\project.ps1 capture   # 生成后保存地表、各采样场与评价、区域格局视角的截图到 artifacts/capture/，并输出各视角渲染耗时
.\tools\project.ps1 build     # 只编译
```

`-GodotPath` 可指定本地 Godot .NET 控制台程序路径。`run` 和 `capture` 可加 `-Seed N` 换用另一个地图种子（截图存到 `artifacts/capture_N/`）。

## 操作

界面按“阶段”组织：地形 → 场地采样 → 场地评价 → 区域格局 → 城镇布局 → 路网 → 街区与地块 → 建筑。

- **相机**：滚轮缩放，WASD 或中键平移，右键或 Q/E 旋转，Home 全图，T 俯视，F 聚焦城镇。
- **顶栏**：地图种子（回车重建）、随机种子、重建地图；生成（F5）、取消（Esc）、“自动”（改参数后自动重新生成）；生成进度；视角按钮；左右面板的显隐。H 隐藏整个界面。
- **左侧阶段列表**：每个阶段和其下节点的状态（绿有效、黄过期、蓝运行中、红失败）与耗时。点阶段（或按 1–8）切换右侧页面；点节点跳到它的参数卡片。
- **右侧“阶段”页**：所选阶段的可视化选项（该阶段相关的图层、地面着色、等高距等，“显示到此阶段”一键切换）和每个节点的卡片：读写的数据、结果摘要、提示、参数。参数用滑条或直接输入，改过的参数旁出现 ↺ 可恢复默认；卡片上可“重跑”或整体恢复“默认”。开着“联动视图”时，选中阶段会自动切换到适合它的显示。地形阶段可改种子、起伏、河宽、森林密度和树木间距，修改后重建地图。
- **右侧“视图”页**：全部显示选项——地面着色（地表 / 各采样场 / 可建设判定、宜居度、通行代价）、城市各图层、等高距、森林/河面/地被与岩石、相机视野。
- **右侧“环境”页**：光照与空气。预设（午后、清晨、正午、黄昏、阴天、薄雾），以及太阳（时刻、方位、强度、颜色、阴影）、天空与环境光、雾（浓度、颜色、空气透视、阳光散射、低处雾）、后期（曝光、饱和度、对比度、环境光遮蔽、泛光）、画风与风（卡通分阶、光照包裹、暗部补光与色调、风力风向）。
- **底部**：鼠标所指位置各采样场的读数和建设限制；左下角是指北针、比例尺和当前画面的图例。
- 所有界面修改只在本次运行有效。

## 仓库

- 地图参数：`configs/temperate_plain.tres`。节点参数是代码中的默认值，在界面上修改，只在本次运行有效。
- Git LFS 管理二进制资源（见 `.gitattributes`），包括插件的 DLL。首次使用先执行 `git lfs install`。
- 地面使用 [Terrain3D](https://github.com/TokisanGames/Terrain3D) v1.1.0（MIT），位于 `addons/terrain_3d`，只保留了 Windows x86_64 的库。升级时从其发布页下载对应 Godot 版本的压缩包，替换该目录并删掉其他平台的库。
- 新克隆的仓库需要让 Godot 扫描一次项目才会加载插件；`tools/project.ps1` 会在需要时自动执行 `--import`。
- 在 Godot 编辑器里保存 C# 文件会把缩进改成 Tab；提交前执行 `dotnet format whitespace` 改回空格，或把编辑器的缩进设置改为空格。
- `.godot/`、`bin/`、`obj/`、`artifacts/` 为生成内容，不纳入版本库。
